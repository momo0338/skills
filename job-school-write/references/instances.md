# School-Write · 实拉核验与操作手册

> 主文件 SKILL.md §三（状态判定五步）的落地细则。**每篇教育招聘稿动笔前必参照本文件执行。**

## 1. 一句话工作流

```
定主词（学校全名 or 教育局）→ 抓公告正文 → 抓齐附件岗位表 → 翻栏目找拟聘用公示
→ 判收官 → 判窗口形态（定期/长期招满即止）→ 做批次差集 → 抓校徽取色 → 才可以动笔
```

**先后顺序不能反。**先写再补核验＝返工＋误导读者风险。

## 2. 必拉的四种文件（按优先级）

| 优先级 | 文件 | 用途 | 典型文件名 |
|---|---|---|---|
| P0 | **公告正文页** | 报考条件、年龄四档、报名四段式时间轴、考核方式、服务期 | `...2026年公开招聘...公告（第二批）.html` |
| P0 | **岗位表**（xlsx） | 岗位明细，唯一权威岗位来源 | `...公开招聘公告（第二批）-岗位表.xlsx` |
| P1 | **拟聘用人员公示** | 判收官 | 省人社厅「省属事业单位招聘」栏的公示条目 |
| P2 | **学校招聘系统页** | 报名入口细节、发布日期核对 | `zp.nuist.edu.cn` |

> ⛔ **只比正文不比附件＝最大坑**。正文常写"详见岗位表"，**实际岗位数/人数/开考比例/考核权重/招聘对象全在附件**。
> 2026-09-29 实测：无锡学院选聘公告的「岗位编号 / 岗位类别 / 开考比例 1:1 / 政治面貌」四项**正文完全看不到**。

## 3. 教育类政务站抓取经验（2026-09-29 实测）

### 3.1 省属事业单位招聘主源：`jshrss.jiangsu.gov.cn`

- 栏目：**「省属事业单位招聘」**，URL 形态 `https://jshrss.jiangsu.gov.cn/art/YYYY/M/D/art_78506_<id>.html`
  - `art_78506` 即该栏目 ID（2026-09-29 实测稳定）
- ✅ **curl 直抓可用**（无需 JS 渲染），带桌面 UA 即可，返回 **UTF-8**，38KB 量级。
- 标题结构：`江苏省人力资源和社会保障厅 省属事业单位招聘 <学校名><年份><公告名>`
- 正文容器里的**正文起止有 TRS 标记**：`begin--> ... end-->`，可按此切正文，避开导航噪声。
- ⚠️ **附件是相对路径 jsp 下载**，必须带 Referer：
  ```
  href="/module/download/downfile.jsp?classid=0&filename=<md5>.xlsx"
  → GET https://jshrss.jiangsu.gov.cn/module/download/downfile.jsp?classid=0&filename=<md5>.xlsx
     -H "Referer: https://jshrss.jiangsu.gov.cn/"
  ```
  实测两份岗位表均 HTTP 200、`application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`。

## 4. 🔴 省属事业单位招聘 14 列岗位表模板（实测）

**两篇公告的岗位表列序完全一致**（同一套省属模板），可直接按列名定位，⛔ 不要写死列号：

| # | 列名 | 字段性质 | 进表？ |
|---|---|---|---|
| 1 | 编号 | 短（`A01`/`01`） | ✅ 进表（**差集主键**） |
| 2 | 岗位名称 | 中 | ✅ 进表 |
| 3 | 岗位类别 | 短（专任教师岗/教学科研岗/…） | ✅ 进表 |
| 4 | 岗位描述 | **长** | ⛔ 出表（高度重复，提为表上一句话） |
| 5 | 人数 | 短 | ✅ 进表（**速览四格用**） |
| 6 | 开考比例 | 短（多为"不设"） | ✅ 进表或提为说明 |
| 7 | 专业要求 | **极长（可 15+ 专业含学科代码）** | ⛔ **必须出表**（§六） |
| 8 | 学历 | 短 | ✅ 进表 |
| 9 | 学位 | 短 | ✅ 进表 |
| 10 | 招聘对象 | 短（不限/应届毕业生） | ✅ 进表 |
| 11 | 其他资格条件 | 中（如"中共党员(预备党员)"） | ✅ 进表 |
| 12 | 考核方式 | 短（`面试权重:100%`） | ✅ 进表或提为说明 |
| 13 | 其它说明 | 短（`纳入编制管理`） | ✅ 进表（**编制性质来源**） |
| 14 | 政策咨询联系方式 | 中（逐岗不同） | 视情况——学院多时**并入"学院"列或群扫一段** |

**表尾行**：两篇都有末行「本次招聘的学科、专业名称参照《…目录》执行」，**必须照录**（读者据此判断自己专业算不算）。

**解析要点（openpyxl）**：
- 第 1 行是**表名**（合并单元格），第 2 行才是**表头**；数据从第 3 行起，末行是目录说明。
- 校验真实行数用 `zipfile` 读 `xl/worksheets/sheet1.xml` 的 `<row r="N">`，`max_row` 可能虚高。
- 本机 `grep "\|"` 对含竖线内容会**静默返回空** → 校验表格内容一律用 python 读。

## 5. 窗口形态判别（🔴 本赛道最高频误判点）

| 形态 | 公告里的原文特征 | 写法 |
|---|---|---|
| 🟢 **定期招聘** | 给出硬截止（常精确到 时:分），无"长期"字样 | 按倒计时写；速览四格填截止时间 |
| 🟡 **长期招聘 / 招满即止** | 「本公告为**长期招聘**岗位，**不设开考比例**，自公告发布 **7 个工作日**之后，根据报名情况，**自行组织考核**。**岗位招满即止**。」 | ⛔ 不得只报名义截止日；**四条一起写成形容词**；**必须先翻拟聘用公示防已收官** |

> ⚠️ **2026-09-29 实测反直觉点**：**两篇都是"定期截止 + 长期招满即止"叠加形态**——
> 报名窗口写"9月4日9:00－12月7日16:00"（看像定期），但正文报名注意事项里明写"长期招聘、不设开考比例、招满即止"。
> ⇒ **只看标题下的日期区间会误判**，必须读到「报名注意事项」。这是本赛道最容易翻车的一处。

## 6. 判收官：四条硬标准

出现**任一**即视为该岗位/该批次**已收官**（不得写"报名中"）：

| # | 标准 | 说明 |
|---|---|---|
| 1 | 存在覆盖全部岗位的**拟聘用人员公示** | 最强标准。省属高校公示挂 `jshrss.jiangsu.gov.cn`，含姓名/成绩/排名 |
| 2 | 出现公示后的**放弃/递补公告** | ⚠️ 但很多教育公告明写「**不递补**」——此时递补机会本就为零 |
| 3 | 明示"本批次招聘结束/岗位取消" | 常见于报名不足被取消的岗位 |
| 4 | 只能确认**部分**岗位已被录用 | 其余岗位写「官方未通报去向」，**不得推断为仍在招** |

> ⛔ **"长期招聘 / 报名截至 12 月 29 日" ≠ 仍在招。**这是最常见误判来源。

### 6.1 ⚡ 逻辑判收官（2026-09-29 回流验证立，省一整轮翻页）

**当报名截止日仍未到时（今日 < 报名截止日），拟聘用公示在逻辑上不可能存在** ——
因为公示只能发生在"考核 → 体检 → 考察"之后，而考核必须在报名截止与资格初审完成之后才可能启动。

⇒ **此时无需翻页到底、无需 ego 逐条扫栏目**，即可判定 **🟢 未收官、可写**，并在核验记录里写明推理链。
> 实测：特师第二批报名截止 2026-12-07、核验日 2026-09-29 → 直接判定"公示不可能存在"。
> 另用 ego 实抓 `jshrss` 栏目 20 条（2026-09-15～09-29）交叉印证：**无一条与特师相关**。

⛔ 反之：**当报名截止日已过**，必须老实翻栏目到底找公示（此前五步法的第 2–3 步照跑）。
⛔ 逻辑判定**只用于"截止日未到"这一种情形**，不得外推成"没搜到就是没有"。**推理链必须写进核验记录。**

## 7. 批次差集法

**适用**：同一学校存在第一批 / 第二批岗位表。

```python
# 按「编号」列取差集（编号是稳定主键）
first   = {"A01","A02","A03","A04","A05"}
current = {"A06","A07"}                 # 第二批
removed = sorted(first - current)
```

**报告三件事**：
1. 总量差：第一批 N 岗 → 第二批 M 岗；
2. 消失的编号清单（**这是文章钩子**："上一批还在网上流传，这一批只剩 N 个"）；
3. ⛔ **不得解释消失原因**——官方没说就写：
   > 「公告与两批附件均未说明这些编号的去向（是已招满、暂停还是转批次），本文不作推断，请以官方后续通报为准。」

**人数闭合校验**：`sum(人数)` 是否等于公告正文写的总数。不等就**必须写清**是在编批次盘子 vs 本批实际释放的差异。

## 8. 校徽抓取与取色（🔴 四级兜底）

**最快路径：直接向朱总要 logo 直链**（hospital-write 实测：比在 CSS 里翻找快得多）。

**自抓顺序**：
1. `curl` 学校官网首页 → 正则抽 `<img src>` → 过滤路径含 `logo`；
2. 拉 CSS 搜 `url(...)` 里的 logo；
3. 仍找不到 → 走 `ego-browser` 取源/截图。

**取色（PIL 只在 venv `envs/default/bin/python3`）**：

```python
from PIL import Image
from collections import Counter
import colorsys
im = Image.open(p).convert("RGBA")
px = [q for q in im.getdata() if q[3] > 200]
vivid = []
for q in px:
    h,s,v = colorsys.rgb_to_hsv(q[0]/255, q[1]/255, q[2]/255)
    if s > 0.35 and v > 0.25:            # job-write 标准口径
        vivid.append(q[:3])
print('有彩度像素占比: %.1f%%' % (100*len(vivid)/max(1,len(px))))
for c,n in Counter(vivid).most_common(6):
    print('#%02X%02X%02X' % c, n)
```

**🔴 四级兜底**：
1. 有彩度众数色 → 采用
2. **有彩度占比 = 0**（🔴 高校校徽常态，实测无锡学院 0.0%）→ **必转**官网「视觉识别系统」/ VI 手册栏目
3. 仍无 → 官网 CSS 主色，⚠️ **须人工判定**（防误采栏目标签色）
4. 仍无 → **问朱总要直链/色值**

⛔ 不得凭"学校＝蓝色/红色"套色。⛔ 不得因为抓不到就随手用近似色。

## 9. 字段裁剪：哪些能写、哪些必须写「公告未披露」

| 字段 | 处置 |
|---|---|
| 岗位、人数、专业、学历、学位、招聘对象 | ✅ 必写，来自附件岗位表 |
| 年龄四档与对应出生日期 | ✅ 必写（**原文整段摘录**） |
| 考核方式与权重、合格线 | ✅ 必写 |
| 编制性质（"纳入编制管理"） | ✅ 有原文则写编内；否则写"公告未披露" |
| **经费渠道（全额/差额/自收自支）** | ⚠️ 全额/差额**只认公告原文**；没写就不写 |
| **办学层次（双一流/双高/省重点/四星级）** | ⛔ 只认官方名单或公告自述，否则不写 |
| 薪酬 / 安家费 / 住房补贴 / 科研启动费 | ⛔ 公告未披露就不写（**实测易被脑补，见 §11**） |
| 消失岗位的去向 | ⛔ 不推断 |

## 12. ⚠️ 本赛道已知的漏项形态（写稿时对照自查）

1. **速览/三宫格的"规模"格不填数字**（实测南信大 09-24 稿）→ 必须写"N 岗 M 人"。
2. **漏"不设开考比例"**（长期招聘的核心机制）→ 必须写。
3. **漏考核权重**（"仅面试 100%" vs "面试60%+专业测试40%"）→ 必须写。
4. **漏"不递补"** → 公告明写就必须照写。
5. **漏"最低服务期年限"** → 必须写。
6. **把"资格初审截止日"当"报名截止日"** → 四段式时间轴里，报名上传截止与初审截止**不是同一天**（实测特师：12-7 vs 12-8）。
7. **漏"只能报 1 个岗位"** → 报名注意事项里的硬约束。
8. **脑补薪酬与安家待遇** → 公告未披露就不写。

## 13. 📌 首篇回流验证的六条实测经验（2026-09-29 特师第二批走完整链路）

> 本次是全技能首篇**端到端**验证（状态判定 → 附件解析 → 7 段成稿 → 排版 → 封面 → 四门禁 → 人工三件套），
> 门禁全绿、官方事实点 39/39 零缺失。下面六条是走通链路才暴露出来的，**纸上设计发现不了**。

1. **判收官优先走逻辑推理**（见 §6.1）——报名未截止 ⇒ 公示不可能存在。省掉整轮翻页与 ego 扫描。
2. **VI 主色可能四级兜底走到底仍不可确证**，这是**正常结果不是失败**。特师实测：校徽灰度零彩度 → 无 VI 栏目 →
   CSS 全被 Bootstrap 默认色污染 → 剔除后只剩插件 link 色。**此时必须标注"待确认"并交朱总**，
   ⛔ 不得因为"总得有个颜色"就把它当成已确证。（本次 `#E10000` 已由朱总 2026-09-29 确认采用。）
3. **校徽常是白色反白版**，白底胶囊上完全不可见。✅ 反色为深色正片 + 标注派生物 + 归档原件（详见 SKILL.md §8.3）。
   🔴 **2026-09-29 累计 8 张实测：江苏 5 所高校校徽 100% 无彩度、100% 白色反白版** → 应作**默认预期**，
   抓校徽时直接按"反色正片"处理，别指望拿到彩色正片。
   📌 **封面只用固定社招母版 + 校徽，不需要学校 VI 主色** —— 只补封面时**无需重新取色**，别做无用功。
4. **加粗密度门禁在该口径下无区分力**（全库 10–24.5 处/屏无差别"超标"）→ 改用**同长度绝对加粗数对标**。
   本稿 146 行，对标同长度南师大（149 行 / 43 处）→ 由 56 处降至 **37 处**。

## 14. 📐 390px 排版实测三条（2026-09-29 朱总「给我看看排版」触发，全部实测）

> **方法**：用 playwright（本机已装）以 390px viewport 渲染**每一篇**排版 → 全页截图目检 + 程序化量溢出。
> ⛔ **不要只靠"目检"**——本轮三个缺陷里有两个目检发现不了。

1. 🔴 **溢出判据必须用 `scrollWidth > clientWidth`，不能只查元素 `rect.right`**。
   南大工程管理学院稿 `documentElement.scrollWidth = 393`（溢出 3px），但
   "遍历所有元素 `rect.right > 390`"返回 **0 条** —— 溢出的是**长 URL 的内部文本**（`<p>` 自身宽度正常）。
   ✅ 写法：`[...document.querySelectorAll('*')].filter(el => el.scrollWidth > el.clientWidth + 1)`。
2. 🔴 **含 URL 的 `<p>` 漏 `word-break:break-all` 是高频缺陷**：3 篇迁移稿 **2 篇漏**
   （南大 4 个含 URL 的 `<p>` 只 1 个带 → 补 3 处；南师大 2 个只 1 个带 → 补 1 处）。补后 393 → 390。
   ✅ 核对：`re.findall(r'<p[^>]*>(?:(?!</p>).)*?https?://.*?</p>', html, re.S)` 要求**每一个都含 `word-break`**。
3. 🔴 **窄屏表格列数是"每格换行"的根因**：特师岗位表原为 6 列时，390px 下**每格都换行**（「应届毕业生」被切成 3 行）。
   ✅ 处理＝**先删冗余列**（「所属学院」与「岗位名称」重复，岗位名本身已含学院名）→ 6 列降 5 列、字号降 12px，
   同时把值缩短（「12月7日 16:00」→ 值「12月7日」＋副行「16:00 截止｜招满即止」；「不超过 40 周岁」→「40 周岁」，表头已写"年龄上限"）。
   📌 **判据**：任何表格单元格在 390px 下估算超 3 行 → 先想"能不能删列/拆值"，再想"改字号"。
