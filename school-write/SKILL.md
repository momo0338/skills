## 一、教育稿的 9 个独有维度（决定写法为何不同）

| # | 维度 | 对写作的实际影响 |
|---|---|---|
| 1 | **学段是第一分界线**：幼儿园→小学→初中→普高→中职→高职→本科→研究生 | 同一"教师"，学段不同则学历门槛、教师资格、编制形态、薪酬口径全不同 |
| 2 | **教师资格分七类**，与学段一一对应 | 不能跨学段上岗（≡ 医院的执业医师资格） |
| 3 | **编制形态多元化** | 编制教师 / 备案制·员额制 / 合同制 / 人事代理 / 劳务派遣 / 特岗教师 / 公费师范生·优师专项 / 定向培养乡村教师 / 县管校聘 |
| 4 | **高校是"考评制"不是"考试制"** | 省属高校主流＝长期招聘、不设开考比例、公告发布 7 个工作日后自行组织考核、招满即止；考核常为"仅面试"或"面试+专业测试" |
| 5 | **年龄＝学历＋职称双轴四档** | 博士 ≤40 / 副高 ≤45 / 正高 ≤50，**必须逐档摘录出生日期原文**（高频首问） |
| 6 | **应届生定义＋择业期写在公告里** | 省属口径「2026-12-31 前毕业取证且报名时无工作单位」；漏写＝把能报的人挡在外面 |
| 7 | **报名是"四段式时间轴"** | 报名上传 / 资格初审 / 陈述申辩 / 异议处理，**四段各自精确到 时:分** |
| 8 | **公告形态与主词判定** | 省属高校「一校一公告」→ 主词＝**学校全名**；中小学常「一局统招多校」→ 主词＝**教育局**。⛔ 不得只写简称（搜索命中靠全称） |
| 9 | **教育专属合规红线** | ⛔保过/保编/包分配；⛔学校排名与水平背书；⛔具体录取分数与位次；⛔涉未成年人及学生个人信息（姓名/成绩/照片）；⛔内部名额/点招/押题 |

## 三、动笔前必做：状态判定（第一道闸门）

### 第 0 步：查草稿箱与 `内容状态.json`——本地没稿 ≠ 没写过

本地三件套可能因清理 / `mv` 事故净消失，但**草稿箱是服务端真源**。若 `wx_draft.py --profile mashang list` 里还有同单位稿（按**单位专名** grep，不按标题精确匹配）＝已写成未群发，此时从零重写＝重复草稿事故。走回捞：

1. `wx_draft.py --profile mashang --json /tmp/<前缀>/raw.json get --media-id <id>` 落盘；
2. 回捞 HTML 里图片是 `data-src="https://mmbiz.qpic.cn/..."` → **下载后转回 `data:image/png;base64`** 再落本地排版稿；
3. 封面丢失就按 §八 用母版＋校徽重出 900×383 RGB，与 `thumb_url` 下载件做深色掩膜 IoU——**浅色渐变母版上 JPEG 压缩会把 IoU 压到 0.85–0.90**（实测 0.8722 / MAE 3.15），MAE 低＋目视同图即可判同一张，不必卡 0.95；
4. 复跑门禁 → `wx_pipeline.py --update-media-id <id>` **原位更新**（media_id 不变，零重复草稿）。

### 五步法（每篇必跑，结果写进源稿核验记录）

1. **取真实发布日期**：区分「网站发布日期」与「文末落款日期」；不一致须在核验记录写明，⛔ 不得择一静默采用。
2. **翻同栏目后续文件**：省属高校 → 翻 `jshrss.jiangsu.gov.cn` 拟聘用人员公示；校级 → 翻学校「通知公告 / 人事处」。
3. **判收官**：出现覆盖全部岗位的拟聘用公示 ＝ 已无投递窗口 → 改写为「机制拆解 / 复盘」型或直接放弃。
4. **做岗位表差集**：同一学校多批次按「编号」取差集。消失的编号 ⛔ 不得断言"已招满"，写「公告与附件均未说明，不作推断」。
5. **定实际窗口**：
   - 🟢 **定期招聘**：有硬截止（时:分）→ 按倒计时写。
   - 🟡 **长期招聘 / 招满即止**：必须把「不设开考比例 + 7 个工作日后自行组织考核 + 招满即止」三条**一起**写出，⛔ 不得只报名义截止日。

> **输出**：必写进源稿核验记录；只有非常规状态（🟡 滚动中 / 🔴 已收官 / 🔵 需确认空缺）才在正文首屏挂状态条。
> **提速技巧**：报名截止日未到 → 拟聘用公示逻辑上不可能存在，无需翻页到底即可判未收官。

### 官网抓不到时：先分「域名不存在」还是「网络不通」

| 现象 | 成因 | 判据 | 处置 |
|---|---|---|---|
| DNS 解析到 `198.18.0.x` | Clash TUN fake-ip 假 IP | 所有 dig（含公共 DNS）都返回该段 | ⛔ 不能据此判域名不存在 |
| DoH `Status:3` | **域名真的不存在（NXDOMAIN）** | `curl -H "accept: application/dns-json" "https://223.5.5.5/resolve?name=<域名>&type=A"` | 去查真实域名，别再重试代理 |
| DoH `Status:0` 有 IP 但直连 000 | 真·网络不通 | 同上 | 走代理重试 |

> ⛔ **不要用 `dig` 判域名存在性**（fake-ip 会劫持）。判 NXDOMAIN 后须 WebSearch 验真实域名，**禁止直接结案为"不可达"**。官网常见 `www.<x>.edu.cn` / `<x>.edu.cn` / `<abbr>.<x>.edu.cn` 三种形态。

## 四、教育招聘 7 段骨架（段标题＝质检硬匹配关键词，不得改写）

| 段 | 段标题 | 硬要求 |
|---|---|---|
| 1 | **码上君划重点** | 首屏四句话内给结论：哪所学校 / 招什么岗 / 什么层次 / 窗口到哪天 / 走不走编制。⛔ 不写"本文分 N 部分" |
| 2 | **招聘速览** | **四格表**：岗位数·人数 ／ 编制性质 ／ 考核方式 ／ 报名窗口。**数字格必须有数字**；长期招聘形态窗口格须带「招满即止」 |
| 3 | **单位与岗位性质** | 办学层次／主管部门／经费渠道（**全额 / 差额 / 自收自支**，未披露不写）／特色定位／岗位归属学院。⛔ 禁百科排比、禁水平背书（写法见 §五） |
| 4 | **招什么人** | 岗位明细表，按 14 列模板裁剪：`编号 / 岗位名称 / 学院 / 人数 / 学历·学位 / 专业要求 / 招聘对象 / 考核方式 / 联系人·电话`。⚠️ 超长专业清单必须**出表格**改成满宽段落 |
| 5 | **报考条件与禁报** | 年龄四档（**逐档摘录出生日期原文**）＋应届生定义与择业期＋禁报情形（现役军人/在读非应届·亲属回避·服务期未满在编） |
| 6 | **怎么报名** | 明文 URL（省属统一平台 `rs.jshrss.jiangsu.gov.cn/index/f/RCRS_0056`）＋四段式时间轴（精确到时:分）＋材料清单＋「只能报 1 个岗位」＋照片规格 |
| 7 | **考核·体检·公示·服务期** | 考核构成与权重／合格线／体检比例与标准（1:1、参照《国家公务员录用体检通用标准（试行）》）／**是否递补**（明写"不递补"须照写）／公示地点与内容／最低服务期年限 |
| + | **常见问答** | FAQ 长尾块，问句库见 `references/seo.md` |
| + | **招聘信息不漏接** | CTA（组件规格沿用 `job-write` §三，⛔ 不自造） |

## 五、写法专项

### 钩子库（一篇挑 2–3 个）

①「不设开考比例」②「招满即止，7 个工作日后自行组织考核」③「仅面试 100%，免笔试」④「纳入编制管理 / 全额拨款事业单位」⑤「各学院各留一个联系人」⑥「年龄四档：博士 40 / 副高 45 / 正高 50」⑦「不递补」⑧「最低服务 3 年（含试用期）」⑨「公示要挂姓名、成绩、排名」⑩ 办学定位型钩子（须原文可核实）

> ⛔ 反例：「机会难得」「不容错过」「最好的学校」「编制很香」——无信息量且部分触红线。
> 🔴 **先跑 §三 状态判定，再谈紧迫感**：不得拿已关闭 / 不存在的窗口制造紧迫。

### 「单位与岗位性质」段怎么写

- ❌ 百科摘录式排比（挂牌／共建单位／在校生数／占地面积／学科评估／院士数）
- ❌ 水平背书（「省内第一梯队」「含金量高」）——触红线且 AI 味
- ✅ 只留**影响选岗决策**的属性，**每段结尾落到"这个岗对读者意味着什么"**
- ✅ **判据**：这句话删掉后读者的**选岗决策**会不会变？不变就删
- ✅ 段末小字一行免责口径（如"办学层次未在公告中说明"）

## 六、表格与长文本分工

- 表格**只装短字段**（编号／岗位名称／学院／人数／学历学位／招聘对象／联系人·电话）；**长字段下沉为满宽段落或列表**。
- 判据：**手机 375px 下单元格估算超过 3 行就得出表**。
- 学院多、岗位多时（如 22 岗），**按学院 / 学部切分为若干小表**，不要一张长表。
- `考核方式` 属短字段可进表，但同列值高度重复时提到表上方一句话说明，列内不重复刷。

## 七、标题与 SEO

- **标题 ≤64 字符**，前 21 字带最强钩子，**必含学校全名 + 岗位类别 + 年份**。
- 教育类高频检索词优先塞前 21 字：`<学校全名>+招聘`、`专任教师`、`教学科研岗`、`博士`、`事业编`、`纳入编制`、`免笔试`、`招满即止`。
- **FAQ 用完整主谓宾自然搜索句**（对齐搜一搜 Answer Box）：
  - ✅「南京信息工程大学教学科研岗招聘是事业编制吗？」
  - ❌「会不会限制？」（内省式缩略，不收）
- 摘要里的"官方入口域名"本赛道常是省属统一平台或学校自有系统（如 `zp.nuist.edu.cn`）。

## 八、封面与 VI

### 8.1 母版
✅ 沿用 `标准社招封面母版.png`（`--type 社招`）；⛔ 不得自创底版。

### 8.2 胶囊 logo

| 情形 | 用什么 |
|---|---|
| 单一学校（一校一公告，主流） | **该校校徽**（官网首页下载） |

| 学校无清晰 logo | 退用上级主管部门 logo，**不得自绘** |

### 8.3 取色四级兜底

> 🔴 **默认预期＝「校徽 100% 无彩度 ＋ 白色反白版」**（江苏高校实测累计 9/9 命中），`logo 取众数色` 规则经常性失效。

1. 校徽有彩度众数色 → 取众数（剔白 / 黑 / 灰）
2. 官网「视觉识别系统」/ VI 手册栏目
3. 官网 CSS 主色 —— ⛔ **必须先剔框架默认色**，且只从模板自有 CSS 取
   - Bootstrap 3 剥离清单：`337AB7 3C763D 8A6D3B A94442 5CB85C 5BC0DE F0AD4E D9534F 31708F 286090 D43F3A EEA236 4CAE4C 46B8DA 357EBD DFF0D8 D9EDF7 FCF8E3 F2DEDE`
   - 只保留路径含 `template<N>` / `theme` / `site` / `style` 的样式表
   - 剔完只剩"单一命中的插件 link 色"不足以确证 → 落第 4 级
4. 向朱总要 logo 直链 / 官方色值 —— **走到这一级是正常结果，不是失败**

**配套规则**：
- ⚠️ 白色反白版 → 按 alpha 反色为深色正片，**须在核验记录标注「派生物」并归档原件**。⛔ 反色 ≠ 自绘，也不等于已确证的官方正片。
- 🔴 **白字蓝底横版校徽一律直接用原图，⛔ 不要抠透明**（抠蓝底留白方块、连白底抠则白字也没了）。
- ⛔ 严禁凭"学校＝蓝 / 红"的印象套色；白字对比度 < 4.5:1 按同色系压深并记录前后值。

### 8.4 封面 logo 归档验收：必须目视，算法只出待看清单

裁卡 `封面.crop((30, 22, 300, 92))`（判白卡用**亮度 > 243 且饱和度 < 14** 联合判据）→ 拼对照图目视（`ImageFont.truetype('/System/Library/Fonts/Hiragino Sans GB.ttc', 12)`，PIL 只在 venv）。

### 推前后必做

| 项 | 正确做法 | ⛔ 常见错 |
|---|---|---|
| **服务端封面回读** | 尺寸一致 ＋ 深色掩膜 IoU ＋ **人眼目检** | 别按 md5 / 字节数判——微信把 PNG 重压成 JPEG，字节数必然不同 |
| **改标题同步** | 顺序：**HTML `<title>` → md frontmatter → md H1** | 漏 `<title>` 会导致服务端标题仍是旧的 |
| **390px 溢出** | 判据 `documentElement.scrollWidth ≤ 390` 且 `scrollWidth > clientWidth` 的元素为空 | 只看元素 `rect.right` 抓不到**长 URL 撑破 `<p>`**（须给每个含 URL 的 `<p>` 加 `word-break:break-all`） |

| **加粗密度** | 用**同长度已发布稿 `<strong>` 数**对标，≤基准 ~120% | 「≤5.5 处/屏」口径全库无一例外超标，无区分力，别当硬判 |
| **token 回归** | 关键 token 存在 + 关键数字至少出现一次，DIFF 逐项溯源 | 别用"数字多重集守恒"当门禁（会把正常去重报成事故） |

### 删段 / 删块的安全做法

1. **按块自身文本判定**：枚举所有 `<section>` 块，取文本以标记词**开头**的那个；⛔ 不要"往上找最近 `<section>`"（会返回父级包裹块，实测误删整段）
2. **加长度守卫**（防骗块 150–1200 字符；实操段 300–2000 字符）
3. **操作前 `/tmp` 备份 + 删除后差异归因**：断言 `added == ''`，并检查 removed 里有无硬信息段关键词
4. 源稿与排版**同步删**；顺手清孤儿注释；删完复跑配平 / CTA 计数 / 390px

### 检查脚本的四类假失败（先疑脚本，再疑稿件）

| 现象 | 真相 | 正确判据 |
|---|---|---|
| `'<td' in h` 断言失败 | 表格是 `<p>` + flex 模拟（微信方言禁 `<table>` / `<th>`） | `'<th' not in h and 'display:flex' in h` |
| 污染词（别家校名）命中 | 出现在核验记录的"扫描范围说明"里 | 扫描前 `split("## 源稿核验记录")[0]` 并剥 frontmatter |
| 「数字丢失 N 项」 | 同句重复次数 / md 表格竖线 / 标注性数字 | 改关键 token 存在性 |
| 逐字终核不一致 | 归一化漏转全角 `＋ ＝ ∶ －` | norm 补齐全角符号 |
| 改完标题报"旧标题仍残留" | 新标题是旧标题的**超串**，`count / find` 必假阳 | 用负向前瞻 `re.findall(OLD + '(?!后缀)', h)`，结果 `[]` 才算干净 |

## 十一·补 · `内容状态.json` 回填的 facts 静默丢弃坑（2026-10-09 实测）

`emit_briefing.py --mark "<单位>" --to draft --facts k=v` **只有匹配到已存在的 batches 条目时才 update facts**（脚本 `_apply_mark` 内 `if facts:` 分支挂在"已命中"路径下）。首次对一个**新单位**同时带 `--facts`，条目会建成 `unwritten→draft` 但 **facts 保持空 dict，无任何告警**。

✅ 正确做法：**跑两次**——

```bash
# 第一次：建条目
emit_briefing.py --mark "<单位>" --to draft --apply
# 第二次：条目已存在，facts 才会写入
emit_briefing.py --mark "<单位>" --to draft --facts deadline=... --facts note=media_id=... --apply
```

判据：`[ok] 新建并置为 draft` ⇒ facts 必丢；`[ok] <单位> ｜ <标题> → draft ｜ facts+k1,k2` ⇒ 生效。
⚠️ 媒体类稿件 facts 里的 `media_id` 是**原位更新的唯一凭据**（`--update-media-id`），丢了就得重发而非改稿，必查。

> 📌 `batches` 的 key 一律是 `unit||title`（双竖线），⛔ 不是脏数据；按 `unit` 前缀 grep 即可。
