# School-Write · 学段 · 教师资格 · 编制形态 · 职称与职务层级 · 政策词典

> **本文是教育稿的知识底座。**写稿时查阅用，**不必通篇写入文章**——按公告实际涉及的学段与岗位挑着用。
>
> ⚠️ **通用免责口径**：本文件记录的是**现行通行口径**，政策会变。
> 任何政策条款写入正文前必须做两件事：① 到**教育部 / 省教育厅 / 省人社厅官网**核对该文件**仍然现行**；
> ② 在正文中写明**文件名或发布年份**。⛔ **不得凭本文件的记忆直接断言"必然如此"。**
> 标 `ⓘ待核` 的条目**未经本次实测确认**，用前必须回官方源。

## 1. 学段词典（稿子里"按学段分组"的依据）

| 学段 | 典型岗位 | 教师资格种类 | 常见学历门槛 | 备注 |
|---|---|---|---|---|
| **幼儿园** | 幼儿教师、保育员 | 幼儿园教师资格 | 幼儿师范学校毕业及以上（部分岗本科起） | 民办园比例高，编制岗稀缺 |
| **小学** | 语文/数学/英语/科学/音体美教师、班主任 | 小学教师资格 | 专科～本科 | ⚠️ 小学资格**不能**教初中及以上 |
| **初级中学** | 各学科教师 | 初级中学教师资格 | 本科 | 初中资格**向下可教小学**，向上不行 |
| **普通高中** | 各学科教师 | 高级中学教师资格 | 本科～硕士 | 高中资格可向下覆盖初中、小学 |
| **中等职业学校** | 专业课教师、文化课教师 | 中职教师资格 | 本科为主 | 专业课教师常另要求行业经历/技能等级 |
| **中职实习指导** | 实训指导教师 | **中职实习指导教师资格** | 学历门槛较低但需**技术等级/职称** | ⛔ 与"中职教师资格"是**两个不同种类** |
| **高职（专科）** | 专任教师、实训教师 | **高等学校教师资格** | 硕士～博士 | 部分岗接受"本科＋高级职称＋企业经历" |
| **本科高校** | 专任教师、教学科研岗、辅导员 | **高等学校教师资格** | **博士为主** | 辅导员岗常另要求中共党员、硕士起 |

> 📌 **写稿用法**：岗位清单表按学段分组；**首屏必须点明这是哪个学段的岗**——读者最先判断的就是"我的资格证能不能用"。

## 2. 🔴 教师资格（教育版的"证书决定资格"）

### 2.1 七类教师资格

依据《教师资格条例》，教师资格分为 **七类**：幼儿园、小学、初级中学、高级中学、中等职业学校、中等职业学校实习指导、**高等学校**。

- **向下兼容、向上不兼容**：高级中学教师资格可教初中/小学；小学教师资格**不能**教初中及以上。
  ⛔ 但**具体岗位是否接受"向下"资格，以公告原文为准**，不得替官方判断。
- **同种类内还有"任教学科"**：资格证上有任教学科（如"高级中学教师资格·数学"），
  ⛔ 学科与报考岗位不一致是否可报，**以公告为准**，公告未说明就写「公告未披露」。

### 2.2 获取路径（两类，别混）

| 类别 | 路径 | 关键点 |
|---|---|---|
| **幼儿园 / 小学 / 初中 / 高中 / 中职 / 中职实习指导（6 类）** | 参加**中小学教师资格考试（NTCE）**：笔试 → 面试 → **教师资格认定** | 考试合格证明有效期一般 3 年（须核现行）；认定需普通话等级等条件 |
| **高等学校教师资格** ⚠️ | **不通过 NTCE**。一般由高校组织**岗前培训 ＋ 教育教学能力测试**，再由省级教育行政部门认定 | ⛔ **高校教师资格通常"先入职、后认定"**，很多高校招聘公告**不要求入职前持有**。**这是最高频误区** |

> 🔴 **推论**：写高校招聘稿时，**不要把"须持高校教师资格证"写成报考条件**——绝大多数公告要求的是**博士学位**，教师资格是入职后认定。
> 公告没写就必须不写（这一条与"硬信息只认原文"同级）。

## 3. 编制形态（教育版，比医院更多元）

| 形态 | 怎么从公告看出来 | ⛔ 不能写 |
|---|---|---|
| **事业编制（编内）** | 公告/岗位表写「**纳入编制管理**」「办理进编手续」「全额拨款事业单位」 | 不得承诺"铁饭碗" |
| **备案制 / 员额制** | 公告写"备案制""人员控制总量管理""员额" | 不得等同于"编制" |
| **合同制 / 人事代理** | 公告写"劳动合同""人事代理""同工同酬" | 不得写"等同事业编" |
| **劳务派遣 / 政府购买服务** | 公告写"劳务派遣""购买服务""第三方公司" | 不得与"单位直接聘用"混谈 |
| **特岗教师** | 写"农村义务教育阶段学校教师特设岗位计划" | ⛔ 不得写"直接入编"——只能写"**服务期满考核合格后按当年政策办理**" |
| **公费师范生 / 优师专项** | 写"公费师范生""优师专项""履约任教" | ⛔ 必须同时写明**履约年限与违约后果**，不得只讲红利 |
| **定向培养乡村教师** | 写"定向培养""定向县任教""协议" | ⛔ 必须写明服务期约束 |

> 🔴 **判定原则**：**只认公告原文用词**。公告没写的（尤其经费渠道、是否备案制），一律写「**公告未披露**」。
> ⛔ 严禁由"是公办学校""省教育厅主管"反推 薪酬/经费/必定有编。

### 3.1 经费渠道（常被混淆）

| 渠道 | 含义 | 实测提示 |
|---|---|---|
| **全额拨款** | 人员经费由财政全额负担 | ✅ 省属高校公告**普遍明写**（如"省教育厅主管的**全额拨款**事业单位"） |
| 差额拨款 | 财政补助一部分 | ⛔ 未写明不写 |
| 自收自支 | 财政不负担人员经费 | ⛔ 未写明不写 |

## 4. 职称序列与岗位等级（高校"我够不够格"的核心）

### 4.1 专业技术职称序列

| 序列 | 中学/小学 | 高校 |
|---|---|---|
| 员级 | 三级教师 | 员级 |
| 初级（助理级） | 二级教师 | **助教** |
| 中级 | **一级教师** | **讲师** |
| 副高级 | **高级教师** | **副教授** |
| 正高级 | **正高级教师** | **教授 / 研究员等** |

### 4.2 职称 ↔ 事业单位专业技术岗位等级对照（通行口径）

| 职称层级 | 对应专技岗位等级 |
|---|---|
| 正高级 | 专技 **一至四级** |
| 副高级 | 专技 **五至七级** |
| 中级 | 专技 **八至十级** |
| 初级 | 专技 **十一至十三级** |

> 🧪 **实测校验（无锡学院选聘公告原文）**：岗位要求「现聘在**专业技术三级以上**岗位，或者在**专业技术四级**岗位上累计工作三年以上」
> —— 三级/四级均落在**正高级（一至四级）**区间，**与上表自洽** ✅
> ⛔ 岗位名称里的"三级""二级"是**岗位内部档次**，具体以公告为准，不做推算。

### 4.3 🔴 高校管理岗位等级（干部选聘赛道必用）

| 职务 | 对应管理岗位等级 | 实测出处 |
|---|---|---|
| 正处职 | **管理五级** | 无锡学院选聘公告原文「现任正处职（管理五级）」✅ |
| 副处职 | **管理六级** | 同公告「副处职（管理六级）两年以上任职经历」✅ |

> ⚠️ 事业单位管理岗位共十级（一级最高）。**一至四级为厅局级及以上**，高校常见的是**五级（正处）/ 六级（副处）**。
> `ⓘ待核`：级别与职务的完整对应表以**现行《事业单位岗位设置管理试行办法》及各省实施办法**为准，跨省引用前必核。

## 5. 政策词典（每条都是潜在钩子，但引用必核）

| 政策 | 通俗含义 | 对哪类读者值钱 |
|---|---|---|
| **高校教师岗位"考评制"** | 省属高校长期招聘不设开考比例、公告发布 7 个工作日后自行组织考核、招满即止 | 所有博士求职者（**本赛道最核心机制**） |
| **中小学教师公开招聘** | 一般由**县/区教育局统招**，走**笔试＋面试**，多设开考比例 | 师范生、代课教师 |
| **农村义务教育阶段学校特设岗位计划（特岗教师）** | 中央财政支持的农村教师岗，**服务期一般 3 年**，服务期满按当年政策办理 | 应届师范生（须同时写服务期与"是否入编以当年公告为准"） |
| **公费师范生 / 优师专项** | 免学费并补助，毕业后按约到指定地区任教 | 高三家长、师范生（⛔ 必写**履约年限+违约后果**） |
| **定向培养乡村教师** | 省级定向培养，毕业后到指定乡村学校任教 | 高三家长、师范生（⛔ 必写服务期） |
| **县管校聘** | 编制在县、岗位在校，教师可跨校流动 | 在职教师调动 |
| **事业单位亲属回避** | 与单位负责人员有夫妻/直系血亲/三代以内旁系血亲/近姻亲关系的，不得应聘组织(人事)、纪检监察、审计财务岗 | 所有人（**公告明文列举，须照录**） |
| **服务期与诚信档案** | 5 年服务期未满的新录用公务员、3 年服务期未满的在编人员不得报考；弄虚作假记入诚信档案库 | 所有人（最易忽略的坑） |

> ⛔ 引用政策**必须写文件名或发布年份并核对现行有效**。
> ⛔ **不得自行解释到具体分数、到年限以外的细节**（如"几年能晋副高"这类，无官方依据不写）。
> 📌 `ⓘ待核`：特岗服务期年数、公费师范生履约年数等**年限数字**，写入正文前必须回**教育部/省教育厅现行文件**核对，本表数字仅供检索方向。

## 6. 容易写错的八处（错一次就是硬伤）

1. 把**高校教师资格**当成报考门槛——它通常是**入职后认定**，公告不要求就不写。
2. 把**中职教师资格**与**中职实习指导教师资格**混为一谈（是两个种类）。
3. 把**小学教师资格**当成可教初中（向下兼容、向上不行）。
4. 把**"资格初审截止日"**当成**"报名截止日"**（四段式时间轴里是两天）。
5. 把**"纳入编制管理"**写成"事业编制"或反之——**只认公告原词**。
6. 把**第一批岗位表**当成现行版（教育招聘分批放岗是常态，必须用最新批次并做差集）。
7. 把**"不设开考比例"**漏掉——这是长期招聘的关键机制，不是套话。
8. 把**"不递补"**漏掉——读者最常见的误解点。

## 7. 每次复用前的复核清单

- [ ] 涉及的法律/政策，文件名与施行年份是否仍现行？
- [ ] 年限类数字（服务期、履约年限、考试合格证明有效期）是否有当年官方出处？
- [ ] 写到政策红利时，是否**同时写出了对应的义务或约束**（服务期 / 违约金 / 诚信档案）？
- [ ] 有无把"可能/部分单位"写成"必然/全部"？
- [ ] 有无把高校教师资格写成报考门槛？
- [ ] 办学层次（双一流/双高/省重点/四星级）是否有**官方名单**出处？
