# 带货视频宣称证据规则

## 目录

1. 必须核验的宣称
2. 证明强度
3. 常见宣称与所需材料
4. 儿童与贴身用品
5. 输出格式

## 1. 必须核验的宣称

出现以下内容时，逐项进入宣称证据矩阵：

- 数字、百分比、等级、使用周期；
- 成分、材料产地、执行标准；
- 抑菌、除螨、除臭、健康、医疗、安全；
- 防水、透气、承重、耐久、长期不变形；
- 价格、折扣、销量、排名、第一或最佳；
- 用户证言、专家身份、品牌授权；
- 儿童、孕妇、老人、贴身用品等敏感人群或品类。

## 2. 证明强度

- **强**：完整真实使用/对比与宣称直接对应，或画面展示可核验资质且商品一致。
- **中**：结构特写或演示支持部分结论，但仍缺长期、定量或适用范围证明。
- **弱**：只有口播、字幕、主观手感或与结论间接相关的动作。
- **无法证明**：没有对应证据，或画面与宣称冲突。
- **不确定**：文字、音频、商品版本或证据归属无法确认。

不要因为宣称出现在字幕、包装或平台文案里，就把它升级为已证实事实。

## 3. 常见宣称与所需材料

| 宣称 | 画面演示能证明什么 | 通常仍需核对 |
|---|---|---|
| 柔软、弹力 | 手感动作、形变和回弹的可见提示 | 主观差异、长期洗穿表现 |
| 透气 | 网眼、薄度或空气/水汽测试的部分提示 | 测试方法、指标和适用条件 |
| 抑菌、除螨、除臭 | 普通特写不能证明效果 | 检测项目、方法、报告、样品和结论范围 |
| A类、成分 | 吊牌或标签可证明商品标注 | 实物一致性、执行标准或检测 |
| 材料产地 | 普通布料特写不能证明产地 | 供应链、吊牌、证书或可核查材料 |
| 不卷边、不变形 | 单次拉伸不能证明长期性能 | 洗涤/耐久测试、时间和条件 |
| 销量、排名、最低价 | 商品画面不能证明 | 平台页面、时间范围、统计口径 |

## 4. 儿童与贴身用品

- 优先平铺、手部演示、产品特写或合规人台。
- 避免未成年人敏感身体展示和暗示性构图。
- 避免羞辱家长、夸大卫生恐惧或把普遍差异说成统一硬标准。
- 不把主观体验证言当作健康、安全或性能证明。
- 涉及更换周期时说明它可能受洗涤频率、污渍、变形、弹性和产品说明影响。

这是一套内容证据与风险检查规则，不替代法律、平台规则或专业检测意见。

## 5. 输出格式

| 原始宣称 | 时间/位置 | 直接证据 | 仍需材料 | 强度 | 决策 |
|---|---|---|---|---|---|
|  |  |  |  | 强/中/弱/无法证明/不确定 | 直接采用/有条件采用/不建议 |

引用数字或等级时保留原始写法，并注明是“字幕显示”“口播听到”“商品标签”还是“平台提供”。不能确定时不要擅自规范化。
