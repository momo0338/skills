## 1. 一句话工作流

```
抓公告 → 抓齐附件 → 翻栏目找后续文件 → 判收官 → 做岗位表差集 → 定真实窗口 → 才可以动笔
```

**先后顺序不能反。**先写再补核验＝返工＋误导读者风险。

---

## 2. 必拉的四种文件（按优先级）

| 优先级 | 文件 | 用途 | 典型文件名 |
|---|---|---|---|
| P0 | **公告正文页** | 硬门槛、流程、联系方式 | `...2026年公开招聘...公告.shtml` |
| P0 | **岗位简介表**（xlsx / pdf / doc） | 岗位明细，唯一权威岗位来源 | `附件1：...岗位简介表.xlsx` |
| P1 | **同栏目后续文件** | 判收官 / 判滚动核减 | 资格复审名单、成绩、体检、**拟聘用人员公示**、空缺通报 |
| P2 | **报名表 / 联系方式表** | 报名入口细节 | `附件2：报名表.doc` |

> ⛔ **只比正文不比附件＝最大坑**。公告正文常写"招聘 N 名"，但**实际开放岗位以附件岗位表为准**，
> 两者不一致时必须以附件为准，并在正文写明差异（见 §5 差集法）。

## 3. 政务站点抓取经验（2026-09-29 实测）

### 3.1 通用
- 先试 `curl` 直抓 + 桌面 UA。政务站**多数无需 JS 渲染**，比想象中好抓。
- 遇 `curl: (35) SSL connect error` → 加 `--tlsv1.2`，或改 `http://` 重试（**崇川 `www.chongchuan.gov.cn` 实测此路有效**）。
- 部分站点列表页目录直接访问会 **403**，但**顶层栏目页**正常（崇川：`/xccqrmzf/sydwzl/` 403，而 `/zkly/zkly.htm` 返回 200）。**规律：优先找顶层栏目路径。**
- GBK/GB2312 站点偶有出现，乱码时用 `iconv` 或 `errors="ignore"` + 复核。

### 3.2 列表页链接藏在 JS 里（崇川型）
列表由 jpage / AJAX 渲染时，`<li>` 的链接写在 `onclick` 而非 `href`：

```html
<li onclick="tz('/xccqrmzf/sydwzl/content/<uuid>.htm')" style="cursor:pointer;">
```

**提取正则**：`(?is)<li onclick="tz\(([^)]+)\)"[^>]*>(.*?)</li>`
再对第 2 组剥离 `<[^>]+>` 取日期与标题，与第 1 组的 URL **按出现顺序对齐**。

验证对齐是否可靠：拿已知 URL（如本次目标公告）在序列中的位置做锚点校验。

### 3.3 正常直出型（无锡滨湖型）
列表页直接 curl 即可拿到 `<li><a href="/doc/YYYY/MM/DD/<id>.shtml">标题</a></li>`：

| 站 | 卫健委公告栏目 |
|---|---|
| 无锡市滨湖区 | `https://www.wxbh.gov.cn/bhws/zfxxgk/gggs/index.shtml` |
| 崇川区（南通） | `https://www.chongchuan.gov.cn/zkly/zkly.htm`（文章落在 `/xccqrmzf/sydwzl/content/`） |

> 📌 **同一份公告常被区人社局、市人社局同步发布**（如 `hrss.wuxi.gov.cn`、`wuxi.gov.cn/doc/...`）。
> 同步发布会出现**收录日期不一致**——这是 MEMORY §六提过的「同稿多发」坑：**按标题归并计数，不按 URL 重复计数**。

### 3.4 附件下载与解析
- 附件路径带日期目录：无锡滨湖 `/uploadfiles/202609/14/...`，崇川 `/xccqrmzf/upload/<uuid>.pdf`。
- **xlsx**：`openpyxl` 载入后用 `iter_rows` 逐行导出；⚠️ 注意**列标题常占两行**（滨湖：第 3 行主标题、第 4 行子标题），需合并后才能对应字段。
- 校验真实行数：openpyxl 的 `max_row` 可能虚高/不准，用 `zipfile` 读 `xl/worksheets/sheet1.xml` 里的 `<row r="N">` 复核。
- **pdf**：`pdftotext -layout` 保表格布局最可靠（`pdftotext` 在 `/opt/homebrew/bin`）。
- ⚠️ 本机 `grep "\|"` 对含竖线内容会**静默返回空**——校验表格/管道内容一律用 python 读。

### 3.5 logo 抓取（朱总 2026-09-29 要求封面用主体医院 logo）
政务站 logo 常不出现在 `<a>` 里。做法：
1. curl 下载首页 → 正则抽所有 `<img src>` → 按路径含 `logo` / `static.../logo` 过滤；
2. 医院官网同理（首页 banner 区常有院徽 PNG）；
3. 下载后用 PIL 取众数色作 VI 主色（MEMORY：PIL 只在 venv `envs/default/bin/python3`）：
   ```python
   from PIL import Image; from collections import Counter
   im = Image.open(p).convert("RGBA")
   px = [p for p in im.getdata() if p[3] > 200]
   Counter(px).most_common(5)
   ```
4. 存 `素材/logos/<拼音缩写>.png`，再由 `job-write/scripts/build_cover.py` 合成封面。

**三种抓取难度与对策**（实测）：

| 情形 | 表现 | 对策 |
|---|---|---|
| 直出 | 首页 HTML 里有 `<img src=".../logonew.png">` | curl 直接下载（例：无锡九院） |
| 藏在 CSS | `<img>` 没有 logo，HTML 里只有 `class="logo"` | 逐个拉 CSS 文件搜 `url(`；仍找不到就转下策 |
| 抓不到 | logo 是 CSS 背景图或 CSS 在压缩包/远端 | ⛔ **不要随手用近似色**；改走 ego-browser 取源/截图，或请朱总人工下载 |

> 🔴 **取色纪律**：PIL 取众数色时**必须剔除纯白与纯黑**（它们是底色与字色，不是 VI 色）。
> 实测无锡九院 logo 众数前两位是 `#1E1A16`（黑字）与 `#02467E`（深蓝 VI），若不去黑会误判成黑色系。

**📌 最快路径：直接向朱总要 logo 直链。**
朱总 2026-09-29 实测给出无锡市第二中医医院 logo 直链 `wxsdezyyy.com/images/up_images/2018424163656.png`（330×81，主色 `#7D430C` 赭褐，白字对比 7.84:1），一步到位。
**先自己抓、抓不到就问**——比在 CSS 里翻找快得多。同时注意同一家医院可能有**多个域名**在跑（二中医：`wxsdezyyy.com` 为图片资源站，`dezyyy.com`/`bhqzyy.com` 为内容站）。

## 4. 判收官：四条硬标准

出现**任一**即视为该岗位/该批次**已收官**（不得写"报名中"）：

| # | 标准 | 说明 |
|---|---|---|
| 1 | 存在覆盖全部岗位的 **拟聘用人员公示** | 最强标准（崇川：2026-05-27 公示覆盖 2 岗全部） |
| 2 | 出现**公示之后的放弃/递补公告**且已办完聘用手续 | 递补机会已封口 |
| 3 | 明示"本批次招聘结束/岗位取消" | 常见于报名不足被取消的岗位 |
| 4 | 若只能确认**部分**岗位已被录用，其余岗位应声明"官方未通报去向"，**不得推断为仍在招** | 保守原则 |

> ⛔ **"长期招聘 / 有效期至 12 月 31 日" ≠ 仍在招。**这是最常见误判来源。

## 5. 岗位表差集法（挖钩子的核心手段）

**适用**：同公告存在多个版本的岗位表（首版 vs 现行版 / 第一批 vs 第二批）。

```python
# 步骤：两份 xlsx 各解析出岗位代码集合 → 取差集 → 核对人数是否闭合
first_codes  = {"01","02",...,"23"}   # 首版
current_codes= {"06","07","08","16","23"}  # 现行版
removed = sorted(first_codes - current_codes)   # 消失的岗位代码
added   = sorted(current_codes - first_codes)   # 新增（罕见但可能有）
```

**报告三件事**：
1. 总量差：首版 N 岗 → 现行 M 岗；
2. 消失的岗位代码清单（**这是文章钩子**："网上流传的那张表已经过时"）；
3. ⛔ **不得解释消失原因**——官方没说就不说。写：
   > 「公告正文与两份附件均未说明这 18 个岗位代码的去向（是已招满、暂停还是转批次），本文不作推断，请以官方后续通报为准。」

**人数闭合校验**：`sum(招聘人数)` 是否等于公告正文写的"N 名"。
- 若不相等 → 通常是**整批次盘子** vs **本批附件实际释放**的差异，**必须写清**（滨湖：公告"23 名"，第二批附件"5 岗 5 人"）。

## 6. 字段裁剪：哪些能写、哪些必须写"公告未披露"

| 字段 | 处置 |
|---|---|
| 岗位、人数、专业、学历学位 | ✅ 必写，来自附件岗位表 |
| 招聘对象（社会人员 / 毕业生 / 不限） | ✅ 必写 |
| 年龄档位与对应出生日期 | ✅ 必写（原文整段摘录） |
| 职称、执业资格、住培证要求 | ✅ 必写 |
| 编制性质 | ✅ 有"办理进编手续"/备案号则写编内；否则写"公告未披露" |
| **经费渠道（全额/差额/自收自支）** | ⛔ 未披露就是未披露，**严禁推测**（MEMORY §二/§七 红线） |
| **医院等级（三甲/三乙/二甲）** | ⛔ 只认卫健委公示或医院官网自述，否则不写 |
| 薪酬、公积金、食宿班车 | ⛔ 公告未披露就不写 |
| 消失岗位的去向 | ⛔ 不推断 |

## 7. 核验记录模板（写在源稿末尾）

固定模板，一行一个结论，**每一项都要能点开验证**：

```markdown
| 项 | 来源 | 状态 |
|---|---|---|
| 公告全文（含发布日期/落款日期/文号） | <URL> curl 直抓 HTTP 200 | ✅ |
| 现行岗位表 N 岗/N 人（附代码） | 附件 .xlsx 逐行解析（sheet 名、标题行位置） | ✅ |
| 首版岗位表（差集用） | <URL> | ✅ |
| 是否存在拟聘用公示（判收官） | 栏目逐条翻查至最新一条 | ✅/🟡 |
| 消失岗位的去向 | 官方未说明 | ⛔ 未采 |
| 编制性质 / 经费渠道 / 医院等级 | 公告原文 / 未披露 | ✅/⛔ |
```
