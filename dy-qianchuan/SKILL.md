# 千川投流数据日报与策略调整

基于巨量千川开放平台 API，每日自动分析投放数据并输出可执行的投流策略。

## 核心思路（源自十一篇行业方法论文案）

1. **先算清真实利润**：表面ROI（GMV÷消耗）≠ 真实ROI（净利润÷消耗）。配置成本参数后，自动核算真实ROI、保本ROI、净利润。
2. **再判断素材健康度**：12维加权评分（消耗稳定性15% + 点击率15% + 转化率15% + ROI达标率20% + 其余8维各5%）。≥8继续投，6-8密切观察，<6准备替换。
3. **衰退三信号**：日消耗、CTR、ROI 同时下滑 = 进入衰退期。
4. **素材库3:1原则**：每3条在投素材至少储备1条备选，低于安全线亮红灯。
5. **分阶段打法**：探索期测试预算50%（日测3-5条）→ 成长期/稳定期15%（3天替换1条）→ 冲量期3倍素材量 → 衰退期10%。
6. **12批复盘**：历史数据积累，识别最佳/最差素材方向，反哺明日策略。
7. **全域流量认知**：全域推广 = 自然流 + 付费流，不是纯付费。自然流占比高 → 实际ROI>设置值；付费占比高 → 实际ROI<设置值。自然流设计寿命约2小时，拉时长越长ROI越低（设15播4小时≈9-11）。
8. **先诊断账号类型再调策略**：付费主导型（优化人货场+素材是核心）/ 高自然流型（维持低ROI冲量，2小时后提ROI保利润）。不诊断就乱调ROI = 不看病乱吃药。
9. **周期化运营（3天+3000展现）**：素材平均生命周期3-7天，以「3天+3000展现」为核心观测阈值。探索期看CTR/3秒停留不纠结投产；成长期追加预算；稳定期储备新素材（预留7天缓冲）；衰退期收缩。
10. **掉量破局四步**：观察30分钟排除大盘 → 排查根因（低效素材/出价竞争力/体验分<4.6/直播转化）→ 收缩衰退素材守住底线 → 补新素材+建新计划+盘活历史素材（50-100元复测）。
11. **看板即作战地图**：看板结构围绕运营决策搭5模块（整体经营→平台对比→商品分析→流量转化→风险预警）。商品四象限（爆款/高毛利/高退款/滞销）。带病增长判断：GMV↑但转化↓ / GMV↑但退款↑ / 订单↑但客单↓ / 推广↑但ROI↓。指标口径必须先统一（GMV/订单/客单/转化/ROI），否则团队各说各话。
12. **工具选型**：DOU+测素材（新手试水，100元起投，转化弱）→ 千川放量（电商核心，设支付ROI）→ 本地推（线下门店LBS 3-10公里）→ 巨量AD（高客单重线索，需专人）。千川入门：新手日预算200-500元起步，跑完学习期（约50个转化事件）；投放时间越短消耗越快、人群越泛、ROI越低。投流本质=测试+迭代，只投不优化是新手最大误区。
13. **AI自动化路线图**：本技能已覆盖9大自动化场景中的3个核心场景（千川商品卡管理/每日销售报表/自家店铺诊断），底层逻辑=数据采集整理+内容批量生产+智能决策辅助。风险提醒：千川API不全开放（已内置--mock/--manual兜底）、三方API需季度维护、数据勿上传不可控平台。扩展方向：直播间实时告警/同行分析/客服/差评监控/生图剪辑。
14. **科学投放体系（15张表）**：账户搭建（结构/命名/预算7:2:1或5:3:2）→ 计划搭建（出价/定向/素材/时段）→ 投放优化（监控/淘汰/预算调整/素材节奏）→ 复盘 → 团队协作。指标基准：CTR行业1.5-3%（预警<1%）、CVR 2-5%（预警<1%）、CPM 50-150元（预警>200）、消耗速度80-100%。2026变化：千川乘方技术服务费减免至0.6%，付费/自然流更割裂、素材质量更重要。
15. **素材判断优先级**：ROI第一（没ROI其他再好也没用）→ 消耗第二（ROI可接受时再看量级）→ 其他数据（点击/完播/千展）仅作验证，不可跳过前两者。素材四分类（ROI×消耗）：爆款跑量（放量）/ 高ROI低量（优先调计划再调素材）/ 潜力素材（搭新计划培育）/ 低效素材（暂停淘汰）。素材端：核心以硬广为主，脚本简单直接，切勿自嗨（投放前换位思考）。
16. **ROI四层漏斗**：素材只是第一层，真正决定ROI的是整条链路——吸引(素材)→匹配(流量)→承接(页面)→放大(策略)。归因决策：CTR低+ROI低优先改素材 / CTR高+ROI低查落地页转化链路 / CTR稳+ROI突降查流量竞争与账户节奏 / ROI持续降+CPA涨综合排查。口诀：先看流量，再看承接，最后才看素材。
17. **素材追投体系**（分步实操手册）：翻倍定锚法=主计划ROI设系统推荐值2倍+10条追投赛马(100元/5h)+消耗10~25块查ROI不达标即关，循环3~5轮沉淀6~8条。追投铁律：追高不追低（转化成本低于平均+千转高于平均才追）、追新不追老（每天30%预算给3天内新素材）。新素材四关激活：随心推试水→全域追投验证→短时叠加起量→自选接力。红线：追投总消耗<主计划20%、一天调ROI不超2次、调控工具无赔付。

## 每日工作流程

### 第一步：准备数据（任选其一）

```bash
# 方式A：拉取真实千川 API 数据（需先配置 config/api_config.yaml）
python3 scripts/run_daily.py

# 方式B：无 API 凭证时用内置示例数据演示
python3 scripts/run_daily.py --mock

# 方式C：手动数据（没有 API 权限时）
python3 scripts/fetch_data.py --manual
# 按提示输入：今日消耗、GMV、CTR、CVR，以及各素材的消耗/点击/转化/ROI
```

### 第二步：查看分析结果

- 看板：`data/daily/dashboard_YYYY-MM-DD.html`（浏览器打开）
- 数据快照：`data/daily/report_YYYY-MM-DD.json`

### 第三步：执行今日操作清单

看板会输出以下清单，按优先级执行：
1. **关停清单**：评分<6 且上线>5天的素材 → 果断暂停
2. **观察清单**：评分6-8 或 上线<3天 → 优化出价/换封面再观察2天
3. **加量清单**：评分≥8 且 ROI 高于目标 → 提升预算/出价
4. **替换建议**：衰退素材 → 按成本×成功率推荐替换方案（换封面→换文案→混剪→复制爆款→阶梯替换→批量测试）
5. **测试计划**：按阶段分配测试预算，新素材消耗≥150元、ROI≥12才通过
6. **库存预警**：主推爆款<5条 / 备选<8条 / 测试中<6条 → 亮红灯

## 核心判断逻辑（供 Agent 分析时参考）

### 利润引擎（analyze.py 的 ProfitEngine）
```
真实ROI = 净利润 ÷ 千川消耗
净利润 = GMV − 退款 − 货品成本 − 运费 − 平台扣点 − 技术服务费 − 达人佣金 − 千川消耗 − 人工 − 场地 − 其他
保本ROI = 千川消耗 ÷ (GMV − 总成本) 的倒数关系，由固定成本/毛利率/退款率推导
保本GMV = 固定成本 ÷ (毛利率 − 退款率 − 平台扣点率 − 其他变动成本率)
```
红灯预警：
- 真实ROI < 保本ROI → 投放亏损，建议缩量或调整
- 退款率 ≥ 30% → 盈亏平衡线，需优化品控售后
- 平台费用占GMV > 15% → 优化佣金结构

### 素材引擎（analyze.py 的 MaterialEngine）
```
健康分 = 消耗稳定性×15% + 点击率×15% + 转化率×15% + ROI达标率×20% + 8个次要维度×5%
得分区间：≥8 健康继续投 / 6-8 关注 / <6 衰退
衰退信号：消耗↓ + CTR↓ + ROI↓ 三信号同时触发
```

### 素材四分类（references/material_judgment.md，ROI × 消耗矩阵）
看板素材表输出每条素材的分类与对应动作：
| 分类 | 特征 | 动作 |
|---|---|---|
| 爆款跑量 | ROI高 + 量足 | 加预算放大 |
| 高ROI低量 | ROI高 + 量不足 | 优先调计划再调素材 |
| 潜力素材 | 消耗正常 + ROI一般 | 搭新计划培育测试 |
| 低效素材 | ROI低 | 暂停/淘汰 |

判断优先级：ROI第一 → 消耗第二 → 其他数据（点击/完播/千展）仅作验证，不可跳过前两者。

### ROI四层漏斗归因（analyze.py 的 RoiFunnelDiagnoser）
看板输出漏斗定位（问题出在吸引/匹配/承接/放大哪一层）与处理建议：
| 情况 | 漏斗定位 | 处理 |
|---|---|---|
| CTR低 + ROI低 | 第一层·吸引 | 优先优化素材 |
| CTR高 + ROI低 | 第三层·承接 | 检查落地页与转化链路 |
| CTR稳 + ROI突降 | 第四层·放大 | 排查流量竞争与账户节奏 |
| ROI持续降 + CPA涨 | 综合排查 | 流量、出价、承接 |

口诀：先看流量，再看承接，最后才看素材。ROI问题按 流量→页面→转化→素材 依次排查。

### 素材追投建议（analyze.py 的 BoostEngine，来自分步实操手册）
看板输出追投建议区块：
- **翻倍定锚法**：主计划ROI设系统推荐值2倍+10条放量追投赛马(100元/5h)，消耗10~25块查ROI不达标即关，循环3~5轮沉淀6~8条优质计划
- **追投铁律**：追高不追低（转化成本低于平均+千转高于平均才追）；追新不追老（每天30%预算给3天内新素材，冷启动周期72h）
- **新素材四关激活**：随心推试水(100/24h)→全域追投验证(100/24h)→短时叠加起量(100/12h→6h→2h)→自选接力（换2个变量防同质化）
- **红线**：追投总消耗<主计划20%；一天调ROI不超2次；调控工具无赔付
- **ROI层级**：降层扩池=ROI降到系统建议值80%（出价=客单价×毛利率÷0.8），只做一次在冷启动期；爬层收割=层级递增+消耗翻倍才调ROI，每次5%

### 阶段识别（自动，周期化运营：3天+3000展现）
| 阶段 | 特征 | 测试预算 | 素材更新 |
|---|---|---|---|
| 探索期 | 新素材前3天，消耗<3000元 | 50% | 每天3-5条，看CTR/3秒停留 |
| 成长期 | 3-7天，消耗爬坡+ROI达标 | 15% | 逐步追加预算放大跑量素材 |
| 稳定期 | ROI稳定 ≥7天 | 15% | 每3天替换1条，储备新素材（7天缓冲） |
| 冲量期 | 大促/爆发期 | 维持 | 每天更新，3倍素材量 |
| 衰退期 | 多条素材跌破保本线 | 10% | 聚焦已验证素材，收缩调整 |

### 掉量排查（analyze.py 的 DeclineChecker，来自周期化运营方法论）
掉量后不急于操作，按流程：先观察30分钟排除大盘波动 → 未恢复逐项排查 → 控本止损 + 新量承接。
排查项：低效素材标记（评分<6近似）、出价竞争力不足（CTR<2%近似）、主力素材投产下滑（消耗TOP素材ROI接近保本线）、账户整体消耗低迷（<3000元）。
破局动作：收缩衰退素材守住底线 → 补全新原创素材+新建全域计划探索流量池 → 盘活历史潜力素材（低消耗但ROI>保本，50-100元小额复测）。

### 新素材测试标准（拒绝单日误判）
- 单条日预算 ≥50-100元（避免"100元平分4条"导致展现不足）
- 每次同步测 2-3 条差异化素材，测试预算占账户日预算 20% 左右
- 测试周期：3天初步判断（前置条件：累计展现≥3000，不足则延长观察期）；7天不轻易关停
- 关停标准：连续7天无起量趋势 且 ROI<目标60% 才关停
- 冷启动期7天内不频繁调整出价、定向与素材

### 风险预警（analyze.py 的 RiskChecker，来自看板设计方法论）
看板输出风险清单（高/中/低三级）与处理动作：
| 风险项 | 触发条件 | 处理动作 |
|---|---|---|
| 退款率过高 | ≥30%（盈亏平衡线） | 优化品控售后，排查高退款商品 |
| 投放亏损 | 真实ROI < 保本ROI | 缩量或调整出价，收缩跌破保本线素材 |
| 转化率偏低 | CVR < 3% | 检查直播间转化/落地页/商品承接 |
| 点击率过低 | CTR < 2% | 优化素材前三秒（沉浸式/价格福利型） |
| 毛利率偏低 | <30% | 优化供应链降进货价，调整商品结构 |

带病增长判断：GMV↑但转化率↓（流量带动但成交效率差）、GMV↑但退款率↑（增长质量有问题）、订单↑但客单价↓（低价促销拉动需看利润）、推广花费↑但ROI↓（推广效率下降）。

### 指标基准（references/qianchuan_framework.md 表8）
看板/风险预警使用的行业基准：
| 指标 | 行业均值 | 健康区间 | 预警线 |
|---|---|---|---|
| 消耗速度 | — | 80%-100% | >120% 或 <30% |
| CTR | 1.5%-3% | >2% | <1% |
| CVR | 2%-5% | >3% | <1% |
| CPM | 50-150元 | <120元 | >200元 |
| ROI | ≥1:3 | >目标值 | <目标值50% |

### 预算分配与调整（references/qianchuan_framework.md 表3/表10）
- 预算分配：成熟账户 **7:2:1**（主力/测试/激进）；新账户 **5:3:2**（核心/探索/备用）
- 预算调整：ROI>目标120%加30-50% · 80-120%维持 · 50-80%减20% · <50%暂停
- 计划淘汰：消耗>预算50%无转化3天停 · CTR<1%两天换素材 · CVR<1%三天停 · ROI<目标50%五天减预算
- 计划命名：[日期]_[营销目标]_[定向]_[素材版本]_[出价方式]_[备注]

### 账号类型诊断（analyze.py 的 AccountTypeDiagnoser，来自全域投放方法论）
看板输出账号类型与对应策略，决定调整方向：
| 账号类型 | 判断特征 | 核心策略 |
|---|---|---|
| 高自然流型 | 自然流占比≥50%，ROI高于设置值 | 维持低ROI冲量，2小时后提ROI保利润 |
| 付费主导型 | 自然流占比低，素材消耗分散 | 优化人货场再降ROI，素材是核心，谨慎拉时长 |
| 均衡型 | ROI稳定且更新频繁 | 稳定投放，按阶段切换测试预算 |
| 探索期账号 | 平均素材消耗<1000元 | 先跑量建立数据模型，加大测试 |

ROI 偏差提醒：自然流占比高 → 实际ROI>设置值（设15跑18正常）；付费占比高 → 实际ROI<设置值。自然流设计寿命约2小时，前2小时GMV要冲到类目中上部。

### 工具选型（references/tool_guide.md）
| 工具 | 定位 | 适用 | 入门要点 |
|---|---|---|---|
| DOU+ | 新手试水 | 测素材/涨粉/曝光 | 100元起投；先看自然数据（完播/互动好）再投；首投100-200元 |
| 巨量千川 | 电商核心 | 抖店卖货要ROI | 需先开抖店且主体一致；新手日预算200-500元；跑完学习期（约50个转化事件） |
| 巨量本地推 | 线下门店 | 到店消费 | LBS 3-10公里围栏；团购成交/线索留资 |
| 巨量引擎AD | 高阶 | 高客单重线索 | 需专人运营，小店不建议 |

千川投放时长注意：投放时间越短 → 消耗越快、人群越泛、ROI越低。投流本质=测试+迭代，只投不优化是新手最大误区。

## 成本参数配置说明（config/cost_params.yaml）

首次使用必须填写真实成本数据：
```yaml
cost_params:
  gross_margin: 0.55        # 毛利率（必填）
  refund_rate: 0.15         # 退款率（必填）
  platform_fee_rate: 0.05   # 平台扣点率
  tech_fee_rate: 0.02       # 技术服务费率
  commission_rate: 0.15     # 达人佣金率
  freight_rate: 0.03        # 运费占比
  fixed_cost_month: 120000  # 月固定成本（人工+场地+其他，元）
  target_profit: 100000     # 目标月利润（用于算目标ROI）
```

## 扩展路线（references/automation_scenarios.md）

本技能已覆盖 9 大自动化场景中的 3 个核心场景（千川商品卡管理、每日销售报表、自家店铺诊断）。按文章建议的优先级，可扩展方向：
1. **直播间投流实时告警**：接入实时数据接口，设阈值（ROI<1.5/转化率降30%）自动推送
2. **同行店铺分析**：定时抓竞品上新/改价/销量，输出对比表
3. **客服自动回复**：意图理解 + 复杂转人工（可挡60-70%重复咨询）
4. **售后差评监控**：自动分类（物流/质量/描述不符）+ 回复建议
5. **主图/短视频批量生产**：AI生图 + 爆款结构脚本生成

风险提醒：千川API不全开放（本技能已内置 --mock/--manual 兜底）；三方API变化快需季度维护；数据勿上传不可控平台。

## 使用约定

- 每日跑一次，建议固定在每日打烊后（如 22:00 或次日早上），数据更完整
- 数据保存在 data/daily/ 按日期归档，连续 12 天以上即可启用"复盘引擎"
- 看板可分享给团队；操作清单是建议，实际执行需结合人工判断
