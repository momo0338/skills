# 真实 ROI 成本核算模型

来源：《千川投放真实ROI成本核算模型（8张表）》- 云谷学社·老田 (2026.07)

## 核心概念

**表面ROI**（千川后台口径）= GMV ÷ 千川消耗
**真实ROI**（利润口径）= 净利润 ÷ 千川消耗

案例：月GMV 50万，千川消耗3.5万
- 表面ROI = 50 ÷ 3.5 = **14.3**
- 扣成本后净利润 7.5万，真实ROI = 7.5 ÷ 3.5 = **2.1**（差近7倍）

## 成本项（9大项）

| 成本项 | 案例值 | 占GMV | 说明 |
|---|---|---|---|
| 退款 | 7.5万 | 15% | 利润最大杀手 |
| 货品成本 | 15万 | 30% | 进货+包装 |
| 运费 | 1.5万 | 3% | |
| 平台扣点 | 2.5万 | 5% | |
| 技术服务费 | 1万 | 2% | |
| 达人佣金 | 7.5万 | 15% | 直播带货 |
| 千川消耗 | 3.5万 | 7% | 投流费用 |
| 人工 | 4万 | 8% | 团队薪资社保 |
| 场地+其他 | 1.3万 | 2.6% | 房租杂费 |

## 关键指标

**盈亏平衡退款率 = 30%**：退款率每升5%，利润少约8750元（按50万GMV）

**保本ROI** = 使净利润=0时所需的ROI
- 案例（固定成本12万/毛利率55%/退款率15%）：保本GMV 31.6万，**保本ROI 5.8**
- 低于保本ROI，投放即亏损

**目标ROI**：想赚10万 → GMV 41.6万，ROI 7.6

## 红灯预警指标

| 指标 | 阈值 | 含义 |
|---|---|---|
| 退款率 | ≥30% | 盈亏平衡线，需优化品控售后 |
| 平台费用占GMV | >15% | 需优化投放和佣金结构 |
| 人力成本占GMV | >15% | 需提升GMV或优化团队 |

## 优化优先级（对比行业基准）

1. 退款成本（基准10-15%，超了优先控制退款率）
2. 货品成本（基准25-35%，优化供应链降进货价）
3. 其他项维持

每优化1%的成本占比，50万GMV下多赚5000元。

## 多账号对比原则

- GMV最高 ≠ 最赚钱，**净利率才是关键**
- 案例：图书号GMV 15万但净利率14.7%最高
- 利润差距>5万时，复制最优账号经验到最差账号
