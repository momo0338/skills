# 千川全域投放认知与ROI偏差分析

来源：《千川全域投放认知与ROI偏差分析工具包（5张表）》- 云谷学社·老田 (2026.07)

## 1. 全域 = 自然流量 + 付费流量

全域推广**不是纯付费**，它包含两部分：
- **自然流量**（平台"送"的，免费）：设计寿命约 **2 小时**
- **付费流量**（花钱"买"的）：投产比天然较低

**为什么同样设15，有人跑18、有人跑8？**
- 跑到18的人：自然流量占比高，自然流把整体ROI拉上去了
- 跑到8的人：主要靠付费流量撑，付费投产比天然低

## 2. ROI偏差的本质

偏差 = 自然流/付费流的**比例变化**

| 情况 | 结果 |
|---|---|
| 自然流占比高 | 实际ROI > 设置值 |
| 付费占比高 | 实际ROI < 设置值 |
| 拉时长越长 | 自然流越少，ROI越接近甚至低于设置值 |

**建议**：每周对照一次ROI偏差分析，动态调整设置ROI。

## 3. 前2小时决定整场命运（自然流设计寿命）

- 前2小时系统给自然流"试水"：GMV达到类目中上部 → 2小时后继续供给；达不到 → 自然流断崖式下跌，后面全靠付费撑
- 规划要点：每15分钟一个节点，明确 GMV 目标节奏、付费配合时机

## 4. 拉时长不是万能药

| 时长 | 结果（设15为例） |
|---|---|
| 2小时 | ≈15（自然流充足） |
| 4小时 | 9-11（自然流见底，全靠付费） |
| 8小时 | 更低 |

**结论**：拉得越长ROI越低，按自然流寿命规划直播时长。

## 5. 账号类型诊断（6维度）

| 维度 | 说明 |
|---|---|
| 自然流占比 | 高/低 |
| 开播在线 | 人数水平 |
| 2小时后在线 | 留存水平 |
| ROI稳定性 | 波动大小 |
| 素材更新频率 | 高/低 |
| 客单价 | 高低 |

### 典型账号类型与策略

| 账号类型 | 核心策略 | 优先级 |
|---|---|---|
| 付费主导型 | 优化人货场 → 再降ROI；素材是核心 | 先优化人货场 |
| 高自然流型 | 维持低ROI冲量；2小时后提ROI保利润 | 维持低ROI冲量 |

**核心原则：先诊断，再开药方。** 不诊断账号类型就乱调ROI，等于不看病乱吃药。
