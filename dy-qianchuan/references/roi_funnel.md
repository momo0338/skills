# ROI 四层漏斗模型与归因决策

来源：《ROI一直做不上去？一线投手复盘发现，真正影响ROI的是这4个关键变量》- 小伍知识胶囊

## 1. 核心观点：不要把所有ROI问题归因于素材

点击率下降看素材、不起量看素材、ROI下降还看素材——因为素材最容易看到。
但素材只是广告系统进入竞争的第一步，真正决定 ROI 的是后面的整条链路。

## 2. ROI 四层漏斗模型

| 层级 | 环节 | 解决的问题 |
|---|---|---|
| 第一层 | 吸引（素材） | 有没有点击 |
| 第二层 | 匹配（流量） | 点进来的是否真正用户 |
| 第三层 | 承接（页面/落地页） | 用户为什么愿意转化 |
| 第四层 | 放大（投放策略） | 系统是否还能持续找到相同用户 |

> 只优化第一层，很难持续提升 ROI。

## 3. 归因决策表（CTR × ROI 组合）

| 情况 | 建议动作 | 原因 |
|---|---|---|
| CTR低 + ROI低 | 优先优化素材 | 用户没有点击 |
| CTR高 + ROI低 | 检查落地页与转化链路 | 点击质量未转化 |
| CTR稳定 + ROI突然下降 | 排查流量竞争与账户节奏 | 未必是素材问题 |
| ROI持续下降 + CPA上涨 | 综合排查流量、出价、承接 | 系统整体效率下降 |

## 4. 三条信息差

1. **点击率高 ≠ ROI高**：点击率解决"有没有人点"，ROI解决"点完有没有成交"。先判断点击质量，再判断成交质量。
2. **同素材不同账户 ROI 不同**：账户学习状态、人群积累、历史转化都影响系统分发。不要只评价素材，要结合账户环境。
3. **ROI下降 ≠ 素材衰退**：可能是竞争加剧、预算变化、流量结构变化。先排查流量，再排查素材。

## 5. 匿名案例（教育行业）

- 背景：CTR 长期 6%+，ROI 连续一周 <1
- 团队误判：素材失效，一周换 20 多版素材
- 实际调整：调整转化目标 → 优化落地页首屏 → 收紧无效流量 → 放缓预算调整节奏
- 结果：素材基本未变，ROI 恢复至接近历史水平
- 复盘：问题不是素材，而是流量质量和承接效率发生变化

## 6. 行动清单与口诀

**口诀**：先看流量，再看承接，最后才看素材。
ROI 问题必须按 **流量 → 页面 → 转化 → 素材** 依次排查。

今日3件事：
1. 不再把所有问题都归因于素材
2. 建立 ROI 四层漏斗复盘流程
3. 每次优化只改变一个关键变量，再观察数据变化
