## 3. 关键表逻辑

### 表1：账户结构（三级）
广告账户 → 广告组 → 广告计划
- 第一层按营销目标：引流组 / 成交组 / 种草组
- 第二层按投放方式：专业版（手动）/ 托管式（AI自动）
- 第三层按素材类型：实拍 / 混剪 / 图文

### 表2：计划命名规范
`[日期]_[营销目标]_[定向类型]_[素材版本]_[出价方式]_[备注]`
例：`0625_成交_莱卡_V3_控成本_女装` → 复盘效率提升3倍

### 表3：预算分配法则
| 账户类型 | 法则 | 说明 |
|---|---|---|
| 成熟账户 | 7:2:1 | 主力70% / 测试20% / 激进10% |
| 新账户 | 5:3:2 | 核心50% / 探索30% / 备用20% |

### 表4：出价策略
| 出价方式 | 适用 | 日预算 |
|---|---|---|
| 控成本 | 稳定跑量的成熟计划 | 不限 |
| 放量 | 新计划冷启动期 | 300-500元 |
| 自定义 | 有明确ROI目标 | 不限 |
| 最大转化量 | 预算充足追求规模 | 1000+元 |

核心原则：**新计划先用放量跑数据（3天），跑稳后切控成本控ROI。**

### 表5：定向设置（L1-L5）
| 层级 | 定向 | 适用 |
|---|---|---|
| L1 | 通投 | 强素材测试期 |
| L2 | 莱卡定向（行为+兴趣） | **新手首选** |
| L3 | DMP人群包 | 有数据积累后 |
| L4 | 达人相似 | 竞品分析后 |
| L5 | 人群包叠加 | 高阶玩家 |

禁忌：不要同时叠加3个以上定向条件，否则计划很难跑出去。

### 表6：素材规格（各投放位置）
| 位置 | 画幅 | 时长 | 达标指标 |
|---|---|---|---|
| 抖音信息流 | 9:16 | 15-60秒 | 完播率>25% |
| 抖音搜索 | 16:9 | 15-30秒 | 点击率>3% |
| 穿山甲 | 自适应 | 15-30秒 | 转化率>1% |
| 抖音商城 | 1:1/4:3 | 10-30秒 | 商品点击率>5% |

### 表8：数据监控基准（核心）
| 指标 | 公式 | 行业均值 | 健康区间 | 预警线 |
|---|---|---|---|---|
| 消耗速度 | 当日消耗/预算 | — | 80%-100% | >120% 或 <30% |
| CTR | 点击量/展现量 | 1.5%-3% | >2% | <1% |
| CVR | 转化量/点击量 | 2%-5% | >3% | <1% |
| CPM | 消耗/展现×1000 | 50-150元 | <120元 | >200元 |
| ROI | GMV/消耗 | ≥1:3 | >目标值 | <目标值50% |

### 表9：计划淘汰标准
| 情况 | 观察期 | 动作 |
|---|---|---|
| 消耗>预算50%无转化 | 3天 | 立即淘汰暂停 |
| 点击率<1% | 2天 | 换素材再试1次 |
| 转化率<1% | 3天 | 淘汰暂停 |
| ROI<目标值50% | 5天 | 逐步减预算 |
| CPM>行业均值2倍 | 2天 | 放宽定向 |
| 计划空跑（有消耗无转化） | 1天 | 立即暂停检查落地页 |

### 表10：预算调整决策
| ROI表现 | 操作 | 幅度 |
|---|---|---|
| >目标120% | 加预算 | +30%~50% |
| 80%-120% | 维持 | 不变 |
| 50%-80% | 观察减预算 | -20% |
| <目标50% | 暂停 | 立即 |

### 表11：素材替换节奏（生命周期3-7天）
| 阶段 | 时间 | 关注 | 动作 |
|---|---|---|---|
| 冷启动 | 第1天 | 消耗速度/CTR | 观察不干预 |
| 起量期 | 第2-3天 | CTR/CPM | CTR>2%加预算 |
| 稳定期 | 第4-5天 | CVR/ROI | ROI达标放量 |
| 衰退期 | 第6-7天 | CPM↑/CTR↓ | 准备替换 |
| 淘汰 | 第7天+ | ROI持续降 | 暂停上新 |

## 4. 三个实战场景
1. **新账号冷启动**：表1规划结构 → 表4-7建首批计划 → 表8-11监控优化 → 表12-13复盘
2. **账户诊断优化**：逐项查 结构/命名/预算/出价/素材
3. **团队标准化**：统一命名 → 交接流程 → 日操作SOP
