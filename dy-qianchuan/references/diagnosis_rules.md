# 素材诊断规则明细

来源：《千川素材衰退期判断工具包（8张表）》- 云谷学社·老田 (2026.07)

## 1. 衰退三信号

判断素材是否进入衰退期，核心只看三个指标，**同时下滑**即为衰退：

| 信号 | 阈值参考 | 说明 |
|---|---|---|
| 日消耗 | 低于峰值50%或<800元 | 系统不再给量 |
| CTR | <2.0% | 内容吸引力下降 |
| ROI | 低于保本ROI的1.2倍 | 盈利空间消失 |

## 2. 12维健康度评分

核心4维占80%权重：

| 维度 | 权重 | 满分标准 |
|---|---|---|
| 消耗稳定性 | 15% | 日消耗≥2000元 |
| 点击率 CTR | 15% | CTR≥4% |
| 转化率 CVR | 15% | CVR≥5% |
| ROI达标率 | 20% | ROI≥保本ROI×1.5 |
| 生命周期 | 5% | ≤7天满分 |
| 消耗趋势 | 5% | 上升趋势 |
| 量级 | 5% | 消耗≥1000元 |
| 获客成本 | 5% | 成本低于均值 |
| CPM | 5% | 低于均值 |
| 竞争度 | 5% | 竞争度适中 |
| 人群精准度 | 5% | 转化人群精准 |
| 时段分布 | 5% | 全天稳定 |

**评分分级**：
- ≥8分：健康，继续投
- 6-8分：密切观察，优化出价/换封面
- <6分：衰退，准备替换（上线>5天果断暂停；上线<3天先优化再观察2天）

## 3. 素材替换方案（按成本×成功率）

| 方案 | 成本 | 成功率 | 适用场景 |
|---|---|---|---|
| 换封面不换内容 | 50元 | 45% | 低成本试探 |
| 换文案不换画面 | 200元 | 50% | 内容结构还行 |
| 混剪原素材 | 300元 | 55% | 素材量不够 |
| 复制爆款结构 | 300元 | 65% | 有爆款可参照 |
| 阶梯替换 | 每天换1-2条 | 70% | 常规运营 |
| 批量测试 | 同时测3-5条 | 75% | 预算充足 |

## 4. AB测试标准

- 每条新素材至少消耗 **150元** 才计入有效测试
- ROI ≥ 12 才算通过
- 通过率 ≥ 50% → 素材方向正确，加大测试量
- 通过率 < 50% → 复盘脚本/画面/出价

## 5. 素材库3:1原则

- 每3条在投素材，至少储备1条备选
- 安全库存线：主推爆款5条 / 备选8条 / 测试中6条
- 低于安全线亮红灯预警

## 6. 分阶段素材策略

| 阶段 | 测试预算 | 素材更新频率 |
|---|---|---|
| 冷启动 | 50% | 每天测3-5条新素材 |
| 稳定期 | 15% | 每3天替换1条 |
| 冲量期 | 维持+ | 每天更新，3倍日常素材量 |
| 衰退期 | 10% | 聚焦已验证素材 |

## 7. 12批复盘机制

- 每批素材下线后记录数据
- 积累12批 → 算平均生命周期、平均ROI
- 识别最佳方向（如主播展示类：8天/ROI16）与最差方向（如场景实拍类：3天/ROI8）
- 最佳方向加大投入，最差方向及时止损
