> **适用范围**：面向南京及江苏省内中小学官方白名单科技、学科、艺术、综合实践类比赛（如五小比赛、青少年科技创新大赛、宋庆龄少儿发明奖、金钥匙、信息素养提升实践活动等），为公众号「满爸爱生活」打造**兼具权威解读、选题实操、绿色通道破局与高转发裂变**的现象级推文。

## 一、 核心复盘：为什么这篇推文具备“破圈爆款”潜质？

回顾全网历史文章，公众号涉及此类比赛时通常陷入三类误区：
1. **公文搬运工**：照抄红头文件，公文用语晦涩，家长看不懂具体怎么做；
2. **名校喜报自嗨**：事后晒奖状，只公布名单，不讲参赛方法与选题规律；
3. **商业培训硬广**：贩卖焦虑推销昂贵培训班，缺乏公信力。

本次创作之所以能打出极致差异化，关键在于抓住了**四个核心破局点**：

- 1. 挖掘隐秘信息差：揭秘市妇儿中心社会机构绿色通道（破除校内名额垄断）
- 2. 真实历史数据破局：调取历届15项特等奖案例，总结特等奖三大公约数
- 3. 极度本地化选题：结合紫金山、玄武湖、明城墙、南京地铁做生活化选题翻译
- 4. 极致清晰视觉交付：6大专属原生组件卡片 + 0丢失草稿直推

## 二、 中小学赛事类推文标准化 8 步执行 SOP

后续遇到其他白名单或官方比赛（如青少年科技创新大赛、宋庆龄少儿发明奖等），一律遵循以下 8 步标准流执行：

### Step 1: 原始公文采证与结构化对账
- **提取全部附件**：红头通知往往将最关键的信息藏在附件（如各区名额分配表、赛道说明、申报表模板）。
- **提取指标数据**：提取各区名额（如江北100、鼓楼/秦淮/江宁各70等），整理成对比表，直接激发家长区域竞争心与转发欲。
- **锁定硬性技术参数**：严格记录视频时长（不超过5分钟）、文件体积（不超过300MB）、申报截止日（10月30日前）、格式要求等。

### Step 2: 调取历届获奖数据库与标杆案例
- **拒绝无依据空谈**：必须调取往届真实获奖名单（如南师附小、北小、力学、成贤街小学、妇儿中心等真实作品）。
- **寻找特殊标杆**：重点找“非传统名校”或“社会通道推荐”获奖案例（如本次妇儿中心推荐的《物联网智能奶箱》获特等奖），用于打破读者的心理门槛。

### Step 3: 提炼“特等奖三大公约数”
所有中小学官方科技比赛评委的底层审美高度一致：
1. **切口极小，扎根真实生活**（水藻、食物水足迹、校长信箱、晾被架，绝不做造火箭式的假大空课题）；
2. **具备完整科研/制作闭环**（发现痛点 -> 控制变量实验/原型图纸 -> 多轮迭代改良 -> 结论与反思）；
3. **跨学科融合与社会关怀**（科学+劳动、智能硬件+助残/适老化关怀、古诗词+气象科学）。

### Step 4: 赛道“生活化选题翻译”与南京本地化灵感库
将抽象的官方赛道说明，转化为孩子与家长一听就懂的南京生活场景选题：
- **小观察（生命/自然）**：紫金山苔藓演替、玄武湖越冬水鸟与晨跑人流、阳台蚯蚓箱、明城墙缝隙植物。
- **小课题（实验/探究）**：南京地铁换乘早高峰实测、保温杯降温与抑菌曲线、书包科学负重分区、地库减速带降噪。
- **小智能（编程/AI/传感）**：饮水机超声波防烫、家庭常备药保质期智能扫描、走廊直角盲区预警、阳台雨感晾衣架。
- **小制作（工程/实物发明）**：爬楼梯省力拉杆箱、课桌防倒洗笔桶、雨天离心沥水架、楼道声控灯防误触开关。
- **小影视（微电影/数字叙事）**：银杏种子旅行定格动画、云锦织造力学探秘、小学生零废弃一天Vlog、城砖缝隙微生态纪实。

### Step 5: 梳理申报双通道与避坑红线
- **双通道拆解**：
  - **通道 A（校内常规）**：校园初选 -> 区教育局汇总平台（wxbs.nje.cn） -> 区级初评 -> 报送市级。
  - **通道 B（社会机构/妇儿中心）**：校外科技机构资质申报 -> 妇儿中心分配账号 -> 专家初审 -> 报送市级（跨校团队最佳通路）。
- **6大避坑红线**：
  1. 一人一件（身份证平台查重拦截）；
  2. 严禁跨通道重复报；
  3. 义务教育阶段在职教师不得担任社会机构指导老师；
  4. 往届市一等奖及以上作品禁赛；
  5. 严禁成人包办代劳（复赛线下现场答辩/演示）；
  6. 影视版权与时长合规。

### Step 6: 视觉卡片组件库（原生微信方言规范）
所有排版必须使用 section 块级容器，杜绝 div 溶解与 position: relative/absolute：
1. **概览卡**：渐变轻蓝底色（#f0f7ff -> #e0effe）+ 圆角徽章；
2. **各区名额分配表**：藏青色（#1e293b）表头 + 白底交替表格；
3. **标杆案例卡**：藏青卡头 + 赛道彩色药丸徽章（tag-blue、tag-purple、tag-amber、tag-rose）+ 痛点解析框；
4. **5大赛道主题卡**：专属淡彩色系（观察绿、课题蓝、智能紫、制作黄、影视红）；
5. **避坑红线卡**：白底红边（#ef4444）+ 01、02 数字醒目标号；
6. **社群与资料卡**：浅蓝渐变卡 + 白色虚线操作框，优雅引导添加满爸微信与进群。

### Step 7: 标题大流量公式与 SEO 摘要
- **标题公式**：[权威发文/地域根词]！[学段赛事+痛点钩子]：[关键词1]、[关键词2]、[关键词3]
  - *实战范例*：《南京官方发文！2026中小学“五小”科技比赛启动：5大赛道选题、历届特等奖拆解、妇儿中心申报通道》
- **摘要规范**：
  - 字符数严格控制在 120 字符以内；
  - **0 emoji**；
  - 不复述标题，高密度覆盖长尾关键词（地域/学段 -> 赛事名 -> 免费/官方 -> 赛道选题/特等奖 -> 申报通道/避坑）。

### Step 8: 一键直推草稿与双向回读验证
- 生成 **900x383（2.35:1）** 蓝金科技教育文字封面（PIL 渲染保存至 /tmp/）；
- 运行 wx_dialect_check.py 进行零违规断言；
- 运行 wx_push_draft.py 直接推入公众号草稿箱；
- 调用 draft/get 回读验证正文长度、标签保留率，清理历史废稿。
