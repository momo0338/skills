## 一、为什么医院稿不能直接用 job-write（7 个独有维度）

| # | 维度 | 对写作的实际影响 |
|---|---|---|
| 1 | **身份三分法**：编内 / 编外（备案制·员额制·人事代理）/ 劳务派遣购买服务 | 「有没有编」是读者第一问，必须首屏答；只写"招聘"会被当成编内，**属误导** |
| 2 | **岗位序列极度分化**：医师 / 医技 / 护理 / 药学 / 公共卫生 / 行政后勤 | 各序列的证、门槛、搜一搜词完全不同；一张混排清单表讲不清，必须分组 |
| 3 | **证书决定资格，而非学历** | 执业医师资格、**住培规培合格证**、职称序列才是硬门槛——这是最值钱的增量，也是家长最不懂的部分 |
| 4 | **长期招聘 / 滚动核减是常态** | 旧的岗位表在网上传播、新的岗位表已悄悄删岗。⚠️ **这是本技能最大的雷**，见 §四 |
| 5 | **层级决定性价比**：三甲/三乙/二甲/社区卫生服务中心 · 大学附属 vs 区属 · 全额/差额/自收自支 | 同样"编内"，三甲和社区是两种人生。这是决策增量，不是背景废话 |
| 6 | **培养周期极长**：5 年本科＋规培＋职称爬坡 | 直接牵出"学医值不值"的家长流量池（L2 线） |
| 7 | **政策红利密集且家长不知道**：定向医学生 / 两个同等对待 / 毕业生身份四种情形 | 每条都是一个钩子，且都是硬政策，可核实、可引用 |

**结论**：job-write 的通用骨架（导语卡 → 数据三宫格 → 单位来头 → 岗位清单 → 条件禁入 → 怎么报名 → FAQ → CTA）在方向上仍然成立，但**三宫格的内容、"单位来头"的定义、FAQ 的词库、以及动笔前的判定流程，全都必须换掉**。

## 三、🔴 动笔前必做：状态判定五步（本技能第一道闸门）

> ⚠️ **医院长期招聘天然带坑**：公告写着"有效期至 12 月 31 日"，岗位可能半年前就招满了；
> 网上流传的岗位表可能是首版，实际已被核减到只剩几个岗。写成"在招"＝误导读者。
> **2026-09-29 崇川（南通市口腔医院）实测：2 个岗已于 5-27 公示拟聘用，网上却仍挂着"有效期至 12-31"。**

**五步法**（每写一篇必跑，结果写进源稿核验记录）：

1. **取真实发布日期**：区分「发布时间」与「文末落款日期」——长期招聘常见**重发/更新版**（滨湖 2026-05-21 首发、2026-09-11 换附件重发），落款日可能仍是旧的。
2. **翻同一栏目的后续文件**（按时间倒序，必须人工确认栏目收录完整）：资格初审/复审名单 → 笔试或面试成绩 → 体检名单/递补 → **拟聘用人员公示** → 空缺或核减通报。
3. **判收官**：若出现覆盖全部岗位的**拟聘用人员公示**，即视为**已收官**招聘的逻辑不适用，只能改写成「**全流程复盘 / 长期招聘机制拆解**」型稿件（或直接放弃发稿）：不再有投递窗口，就没有 CTA 转化位。
4. **做岗位表差集**：把首版岗位表与现行版附件逐行比对（按**岗位代码**取差集，不按标题——标题会微调）。消失的岗位代码 ⛔ **不得断言"已招满"**，官方未说明去向就写「公告与附件均未说明，不作推断」。
   > 2026-09-29 滨湖实测：首版 23 岗 → 现行第二批仅 5 岗（代码 06/07/08/16/23），18 个代码消失；这本身成了全稿最强钩子。
5. **定实际窗口**：长期招聘的真正截止不是写明的截止日，而是「**不定期启动考试、岗位招满即止**」。必须把它写成形容词，不能只报 10 月 31 日。

**输出**（分两处，别混）：
- **必写**：源稿末尾核验记录里留痕——「是否存在覆盖全部岗位的拟聘用公示｜栏目逐条翻查至最新｜结论＋日期」。
- **条件性**：只有判定为**非常规状态**（🟡 滚动核减中 / 🔴 已收官 / 🔵 需先确认空缺）时，才在正文首屏挂状态条卡片并附证据链（文件名＋日期＋URL）。
  🟢 常规在招**不挂卡片**，把结论并入三宫格即可（朱总 2026-09-29 实测：常规在招再挂状态条＝与三宫格复述，判为冗余）。

## 四、L1「医院公告稿」骨架改造（相对 job-write）

| 段 | job-write 通用写法 | **hospital-write 改法** |
|---|---|---|
| 前置 | — | ◐ **「还能不能投」状态条＝条件性挂载**（§三 产物）。判定五步**必做**（防误导），但**只有非常规状态才在正文挂卡片**：🟡滚动核减中 / 🔴已收官 / 🔵需先确认空缺。🟢 常规在招**不挂**——三宫格的「截止日＋招满即止」已经表达了，再挂就是复述（朱总 2026-09-29 第五砍实测） |
| 导语卡 | 场景化导语 | 保留；医院稿的钩子常来自**反差点**（见 §五钩子库） |
| 数据三宫格 | 截止 / 单位性质 / 招聘类型 | 🔄 改为 **编制性质 / 报名截止（＋招满即止提示）/ 岗位数·人数**。「单位性质」→ 换成医院版三层属性（见下） |
| 单位来头 | 简介 + 条件性解读框 | 🔄 改为 **层级属性卡**：医院等级（三甲/三乙/二甲/社区）· 是否大学附属 · 区属/市属/省属 · 经费渠道（全额/差额/自收自支）。⚠️ 四项任一项公告未披露，就写"公告未披露"，**不得推测等级** |
| 招什么人 | 一张清单表 | 🔄 **按序列分组**（医师 / 医技 / 护理 / 药学 / 行政），每组表头加「**所需证书**」列 |
| 条件与禁入 | 年龄上限 + 禁入 | 保留；医院稿**必须补「年龄四档放宽」**（博士/中级/高级/基层岗硕士各档对应出生日期），这是医院类独有且高频问到 |
| 怎么报名 | 明文 URL + 流程 | 保留；医院常见**邮箱投递**（无在线系统）与「邮件主题格式」必须逐字给出 |
| FAQ | 通用招聘问句 | 🔄 换成**医院专属问句库**（见 `references/seo.md`），至少覆盖：有没有编 / 要不要住培证 / 应届生能不能报 / 社区岗值不值 / 高级职称年龄放宽 |
| CTA | 通用组件 | 沿用 job-write 组件，不变 |

**医院稿新增四个可选模块**（适配即挂，不强行凑字数）：
- **证书与时间轴**（L1/L2 通用）：执业医师资格 → 住培 → 职称的年限与顺序
- **身份认定**：应届 / 择业期 / 该公告定义的"毕业生"四种情形 + 两个同等对待政策
- **违约与约束**：最低服务期、失信库记录年限、N 年内未取得执业资格即解聘
- **家长向学业规划**（仅当岗位体系含护理/大专/定向岗时）：从招聘岗位倒推志愿填报

### ⚠️「单位来头」段到底怎么写（2026-09-29 朱总判"很 AI"后立规）

- ❌ **不要写成百科摘录**：`等级 —— 挂牌 —— 附属 —— 床位 / 卫技人数 / 高级职称数 / 院士工作站 / 年门急诊量` 的排比罗列，是本技能犯过的最重 AI 味（读起来就是从官网简介抄的）。这些数字对读者选岗没有影响。
- ❌ **不要写水平背书或含金量评价**：「省内第一梯队」「含金量主要就在这点上」「和上面两家不在一个层级上」——既触 §八 红线 2（禁医院水平背书），又显 AI。
- ✅ **一个单位一段，只留影响选岗决策的属性**：等级 / 附属关系 / 区属·市属 / 与本次岗位的匹配关系，**每段结尾落到"这个岗对读者意味着什么"**：
  - 「三个技术骨干岗全部卡『高级职称＋三年三甲经历』——它要的是能直接上手的人」
  - 「招的是学科带头人，带学科建设的角色，跟技术骨干不是一回事」
  - 「唯一面向 2026 年毕业生的岗位在这里，门槛也最低——执业医师资格＋住培合格证」
- ✅ **判断标准**：这句话删掉之后，读者的**选岗决策**会不会变？不变就删。
- ✅ 免责口径放段末小字一行（如"等级与属性取自官网自述或卫健委公示；经费渠道公告未披露"），不要单独占一段。

### ⛔ 改造骨架时的硬约束（2026-09-29 回流验证实测立规）

`job-write/scripts/verify_draft.py` 对**段标题文字指纹**做硬匹配，源稿缺任一段即报 error。
因此**医院化改造只能换内容、不能换这批标题词**——写「单位来头：三家用人单位的层级与属性」而不是「层级属性卡」。

| 指纹（命中任一即可） | 医院版内容怎么填 |
|---|---|
| `码上君划重点` | 导语卡不变，钩子用 §五 钩子库 |
| `数据三宫格` | 三格改为 **编制性质 / 报名截止（＋招满即止）/ 岗位数·人数** |
| `单位来头`｜`单位简介`｜`公司规模`｜`公司简介` | 填 §四 的**层级属性卡**（等级/附属/隶属/经费渠道） |
| `招什么人`｜`招哪些`｜`招聘需求` | 按**序列分组**的岗位表，表头加「所需证书」列。⚠️ **超长字段（专业清单、条件长句）必须从表格里拿出来，改为满宽段落/列表**，见下方「表格与长文本的分工」 |
| `资格条件`｜`应聘基本条件`｜`学历口径`｜`学历与年龄`｜`硬门槛` | 年龄四档 + 禁入 + **证书模块** |
| `怎么报名`｜`如何报名`｜`报名流程` | 邮箱/报名系统 + 主题格式 + 材料清单 |
| `常见问答`｜`FAQ` | `references/seo.md` 医院专属问句库 |
| ~~`实操建议`~~｜`码上君建议`｜`行动建议` | ⚠️ **可选段（2026-09-29 朱总裁定）**：医院稿写得再多也容易沦为前文复述，盐城三院篇经一轮重写仍被判无增量 → **直接删掉整段、接 CTA**。`verify_draft.py` 已同步降为 `OPTIONAL_BLOCKS`，不再报错 |

> 医院增量模块（证书 / 身份认定 / 违约约束 / 状态条）**作为二级小标题挂在上述八段之下**，
> 不要另起与八段平级的标题，否则会肢解骨架、触发 (G) 项「源稿↔排版反向核对」误判。

**⚠️「实操建议」段：必须写"建议"，不能写"条款摘录"（2026-09-29 朱总判两次"没用"后立规）**：

第一次被判冗余后，我把内容换成「正文其他段没写过的新事实」（限报 1 岗、定向委培须同意报考证明、递补规则）——**仍被判"没用"**。
根因：段名叫**实操建议**，读者期待的是**判断和动作**，而换进去的仍是公告条款的转述（"公告写明……""公告规定……"）。**"新事实"不等于"有用的内容"**。

- ⛔ **禁止**：「公告写明…」式的条款转述、事实罗列。
- ✅ **必须是三条以"读者"为主语的建议**，三类取材：
  1. **对号入座**——帮读者判断这条公告跟自己有没有关系（"这 5 个岗是给两类人准备的……两边都不占，这次可以放一放"）
  2. **算账自查**——把硬条件翻译成读者要核对的项目（"① 三年三甲经历是否连续 ② 论文篇数是否达标 ③ 五年能不能留在本地"）
  3. **时间安排**——告诉读者哪一步最费时间、现在就该动（"材料里最费时间的两样，今天就去办"）
- ✅ **双重检验（缺一不可）**：
  1. **主语检验**——这句话的主语是**"读者"**还是**"公告"**？是公告就重写。
  2. **信息检验**——**这条信息在正文上文是否已经出现过？出现过就不是建议，是复述**。
     > 🔴 2026-09-29 盐城三院篇二次返工实测：首版三条虽已是"读者主语"，但**内容基本是复述状态条与招聘段**（"硕士及以下没机会""别等 11 月 30 日"），被朱总一句"这个你觉得有用吗"打回。
     > 改后三条各自携带**上文没有的信息**：① 专业口径差异带来的**选岗判断**（科研岗只要基础医学／临床岗收临床类）② "直接考察"下**业绩材料该做成清单**的准备法 ③ **公告未披露限报规则**的缺口提示＋两步报名别漏。
- ✅ **取材捷径**：写这三条前，先问自己"正文里还有哪些**读者需要行动、但上文没说怎么做**的点？"——
  专业与岗位的匹配关系 / 材料怎么组织 / 公告**没说清**的规则（限报、体检标准、递补细节）/ 易漏的操作步骤（双通道报名只做了一步）。
- 📌 配套取舍：被判"非决策信息"的条款（限报 1 岗、定向委培材料、递补规则等）**从正文移除**，改为在源稿核验记录里留一行，注明"未入正文（判为非决策信息）"——信息不丢，版面不臃。

**⚠️ 表格与长文本的分工：长字段必须"出表格"（2026-09-29 盐城三院篇实测）**：
医院岗位表常带**超长专业清单**（内科岗一口气列 15 个专业方向）。把它塞进多列表格会出事——盐城三院首稿 5 列表中「专业方向」列在手机 375px 下被挤到**每格约 11.5 行**，一行岗位占掉半屏。
- ✅ **正确分工**：**表格只装短字段**（序号／岗位名／人数／学历／证书要求），**长字段下沉为满宽段落或列表**（"内科学（含…）、老年医学、…"整段铺满宽，每行 26 字左右，110 字＝4 行）。
- ✅ 效果对照：改造后同一单元格的渲染行数从 **11.5 行 → 2.4 行**，专业信息一字未删。
- ✅ 判断口径：**手机 375px 下，任何表格单元格估算超过 3 行就要考虑出表**。
- 📌 同构做法参考：滨湖篇把 9 列拆成「清单表 6 列 ＋ 证书表 3 列」，本技巧是同一思路的更彻底版本。

**⚠️ 加粗预算：首稿就控制在 20–25 处（2026-09-29 盐城三院篇实测）**：
医院稿段标题多、表格多，加粗极易超 `verify_draft.py` 的 5.5 处/屏门禁 —— 盐城三院首稿写 **50 处（8.33/屏）超限**，按 job-write §九「逐条白名单降粗」压到 **24 处（4.00/屏）** 才达标。
- 降粗优先级（先删这些）：表格单元格内的重复加粗（表头已说明的不必再粗）→ 段内标签词（"英语：""第一步："这类）→ 电话号与日期 → 与相邻加粗语义重叠的。
- 必须保留：**硬数字与硬门槛**（人数/年龄线/合格线/分数门槛）、**关键结论**（编制性质/是否笔试/招满即止）。
- ⛔ 禁用"字数超过 N 就批量去粗"，只能逐条点名（job-write §九 硬纪律）。

**⚠️ 某一段被判"冗余"时的正确做法（2026-09-29 朱总三次砍稿实测）**：
八段中任一段**都不能删**——删了必报 error。朱总先后砍掉「旧版本岗位表对比」「公告正文人数与附件人数差异」「实操建议里复述过的事实」，
正确处理方式是**换内容而不是砍段**，但换什么内容要按段落功能定（见上条：实操建议＝判断与动作，不是事实）。
> 📌 由此形成的取舍口径：**只呈现读者能直接用的当下事实**；公告内部的数字打架、历史版本差异一律不进正文，只在核验记录留痕。

## 五、L1 常用钩子库（哪几句是"别人没有的"）

按出现频率排序，一篇稿挑 2–3 个即可：

1. **"这 ≠ 还剩这么多岗"** —— 岗位表跨版本核减（差集）
2. **"23 个岗里，只有 1 个应届生能报"** —— 招聘对象分布反差（社会人员 vs 毕业生）
3. **"不要等截止日：招满即止，随时开考"** —— 真实窗口 vs 名义截止
4. **"有没有编，看这一句"** —— 备案号 / "办理进编手续" / 经费渠道
5. **"不是看学历，是看证"** —— 执业医师＋住培＋职称的硬门槛解释
6. **"论文会被查水刊"** —— 中科院预警期刊不予认可等条款
7. **"放弃的代价"** —— 失信库 3 年、服务期、解聘条款

> ⛔ 反例（不要写）："机会难得""不容错过""最好的医院""这个专业很吃香"——无信息量且部分触及医疗合规。
> 🔴 **另一类反例（2026-09-29 立）**：不得拿**已关闭或不存在的窗口**制造紧迫感。例如在"拟聘用公示已完成"的公告上写"错过这批等三个月""赶在截止前投"——把流量建立在一个不存在的机会上，属信息失真，比文风问题严重得多。**先跑 §三 状态判定五步，再谈紧迫感。**

## 六、L2「医学升学与择业稿」（面向学校 / 学生 / 家长）

> 朱总 2026-09-29 拍板：**两条线都要**。L1 吃"精准招聘流量"，L2 吃"泛家长流量"，后者才是"学校、学生、家长"诉求的主战场。

| 项 | L1 医院公告稿 | L2 医学升学与择业稿 |
|---|---|---|
| 锚点 | 一份具体公告 | 政策文件 / 公开统计数据（院校名单、分数线、卫健委年鉴等） |
| 必做 | §三 状态判定五步 | **数据溯源三件套**：数据出处＋口径年份＋原始链接 |
| 骨架 | §四（公告线） | 见 `references/careers.md` |
| 主要读者 | 求职者、在职医生 | 高三家长、在校医学生 |
| 风险 | 岗位过期 | **政策年份过期、地域口径混用、给医院排名** |

**L2 三条硬纪律**：
1. ⛔ **不得给出填报建议到具体分数**（不掌握各省当年录取数据，属编造）→ 只能写"位次/批次口径以当年省考试院公布为准"。
2. ⛔ **不得给医院排名或水平背书**（"江苏最好的三家"）→ 可写客观属性（等级、附属关系、重点专科数量），且必须有官方出处。
3. ⛔ **政策类内容必须写明文件号或发布年份**，跨年复用前**必须复核是否现行有效**。

## 七、封面 logo 规则（朱总 2026-09-29 拍板）

**胶囊内放什么 logo，按「招聘主体」判定：**

| 情形 | 用什么 logo |
|---|---|
| 单一用人单位（"XX 医院 2026 年招聘"） | **该医院 logo**（官网首页下载） |
| 区/市卫健委统招多家下属事业单位 | 统招主体 logo（区卫健委 logo 或区政府 logo），并在正文首段点明各用人单位 |
| 医院无清晰 logo（只有文字标题图） | 退用上级主管单位 logo，**不得自绘** |

- **母版仍走 `job-write` §六**：B 线（编制招考 / 面向社会人员）＝ **`标准社招封面母版.png`**；⛔ **不得自创底版**。
- logo 必须**从官网首页实拉**（`curl` 抓 static/images 或 header 区的 logo 路径），下载后转 RGB 存 `素材/logos/<拼音缩写>.png`。
- ⚠️ 政务站 logo 常藏在 JS/CSS 里，抓取经验见 `references/instances.md` §3。

### 7.1 先破一个误区：医院不是"红白"（2026-09-29 朱总提出后立规）

- ⛔ **不存在"医院 = 红色"的行业规则**。国内公立医院 VI 主色**红、蓝、绿、紫都有，各院独立制定**，必须逐院实拉，禁止凭印象套色。
  - 实测反例：**无锡市第九人民医院（三甲骨科）主色是深蓝 `#02467E` ＋金 `#C7A24C`，不是红色。**
- 容易被误认为"医院就是红白"的那个东西，是**医疗机构通用标识**——医院门口、指路牌上的**红底白十字**。它是行业指引标识，**不是医院自己的 VI**，⛔ **不得拿它当公众号配色依据**。
- 🔴 **法律红线**：普通医疗机构**不得使用红十字标志**。红十字是国际人道主义保护标志，其使用由《中华人民共和国红十字标志使用办法》规范，仅红十字会、武装部队医疗机构等可依法使用。因此医院院徽里不会有标准红十字（多为变形十字或其他图形）。
  - ⛔ **写稿与做图一律不得自行添加红十字元素**，也不得描述某医院"采用红十字标志"。

### 7.2 取色规则（唯一合法路径）

| 情形 | 取谁的色 |
|---|---|
| 单一医院 | 该院**官网首页 logo** 的众数色 |
| 区/市卫健委统招多家下属单位 | **统招主体**（卫健委/区政府）logo 众数色 |
| 医院无清晰 logo | 退用上级主管单位 logo；⛔ **不得自拟品牌色**（同 job-write §6.5 禁自创底版） |

**四步流程**：官网首页下载 logo PNG → PIL 取众数色（**剔除白/黑/灰**，这两个是底色与字色而非 VI 色）→ 计算白字对比度 → **不足 4.5:1 则按同色系压深**（例：梁溪 `#E40900` → 压深为 `#C60800` 用于正文主色）。

> ⚠️ **logo 抓取失败时的兜底**：部分医院官网 logo 是 CSS 背景图（如无锡市第二中医医院 `dezyyy.com`），`curl` 抓不到 `<img>`。此时改走 **ego-browser 截图/取源**或人工下载，⛔ 不要因为抓不到就随手用个近似色。

## 八、医院专属合规红线（job-write 没有，逐篇必查）

1. ⛔ **禁止任何诊疗建议**：不得写疾病治疗、用药方案、养生建议。蹭医疗健康话题会被判医疗类违规。
2. ⛔ **禁止给医疗机构做水平背书或排名**："最好的三甲""省内顶尖"等表述会被投诉且难申诉。只写可核实的客观属性（等级、附属关系、重点专科数量），且必须带官方出处。
3. ⛔ **禁止承诺「包就业 / 包分配 / 包编制」**：定向医学生也只能写"有编有岗，须履行服务期约定"。
4. ⛔ **禁止使用患者案例、就诊故事、疗效描述**。
5. ⛔ **禁止把未经披露的医疗收费、薪酬待遇数据写成确定值**——薪酬除非公告原文披露，否则写"公告未披露"。
6. ⛔ **医院等级（三甲/三乙/二甲）只认卫健委公示或医院官网自述**，不得凭印象；查不到写"公告未披露"。
7. ⛔ 沿用 `job-write` §七全部通用红线（不搬运、来源声明、不声明原创、不复制别家二维码）。
8. 🔴 **继承 job-write 硬红线最高原则**：人数、截止日、岗位、学历、证书要求 **100% 可核对公告原文或官方附件**；缺口一律写「公告未披露」。

## 九、标题与 SEO（打法继承 job-write §四，词库见 references/seo.md）

- **标题 ≤64 字符**，前 21 字带最强钩子；必含 **城市 / 区名 + 单位名 + 年份**。
- 医院类**高频检索词优先塞前 21 字**：`<区名>+<医院名>+招聘`、`<专业>+编制`、`编内`、`长期招聘`。
- **FAQ 必须用完整主谓宾自然搜索句**（对齐搜一搜 Answer Box），例如：
  - ✅「无锡市第九人民医院招聘是编内还是编外？」
  - ✅「没有住院医师规范化培训合格证能考事业编吗？」
  - ❌「会不会限制？」（内省式缩略，不收）
- 摘要四必含中的"官方入口域名"在医院稿里常变成**邮箱**（如 `wxbhwjwrsk@126.com`）或报名系统域名。
