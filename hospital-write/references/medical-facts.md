## 1. 岗位序列词典（稿子里"按序列分组"的依据）

| 序列 | 典型岗位 | 通常要求的证书/资格 | 常见学历门槛 | 备注 |
|---|---|---|---|---|
| **医师（临床）** | 内科/外科/儿科/妇产科/急诊/麻醉/全科等 | **执业医师资格（注册）**＋**住院医师规范化培训合格证**；引进岗另加职称 | 本科～博士 | 医院招聘的主力序列，也是门槛最高的一支 |
| **医技** | 医学影像、超声、核医学、检验、病理、输血、康复治疗、营养 | 相应**技师/技士**资格；**影像诊断岗常要求执业医师资格**（写报告的需要） | 大专～研究生 | ⚠️ 医技 ≠ 医师，配错的讹误会误导考生 |
| **护理** | 护士、助产士、专科护士、护理管理 | **护士执业资格**（考试＋注册）；助产另需母婴保健技术考核合格证书 | 大专～本科 | 护理岗学历门槛常被家长误传为"本科起步"，以公告为准 |
| **药学** | 药剂科/临床药学/静配中心 | 药师**职称**（初级师/主管药师）或**执业药师**（执业资格，社会药店导向更强） | 本科～研究生 | 医院药剂岗通常走职称体系，不是"执业药师=医院药师" |
| **公共卫生** | 预防医学、院感、疾控对接、精防医师 | 执业医师（公共卫生类别）或相应专业背景 | 本科～研究生 | 「精防医师」等岗位常要求 **执业医师资格＋住培合格证** |
| 行政后勤 | 医务科、质控、病案、信息、财务、基建、宣传、党办 | 一般不要求医技类证书，部分岗位要求专业资格（会计、软考等） | 本科～研究生 | 常被求职文章忽略的入口，值得单独成段 |

> 📌 **写稿用法**：岗位清单表按上表分组，每组表头加「所需证书」列；家长看不懂"这份工作要不要证"，这正是增量。

## 2. 证书与时间轴（讲清楚"不是看学历，是看证"）

### 2.1 医师序列三件套

| 阶段 | 是什么 | 现行通行口径 |
|---|---|---|
| ① **执业医师资格** | 行医入门资格，须考试＋注册 | 高等学校医学专业本科以上学历者，在执业医师指导下于医疗/预防/保健机构**试用期满一年**可报考；大专学历须先取得**执业助理医师**执业证书并在相关岗位工作满一定年限方可报考（《中华人民共和国医师法》，2022-03-01 起施行） |
| ② **住院医师规范化培训合格证**（住培证） | 毕业后在培训基地接受的系统化培训证明 | **一般为 3 年**；存在并轨专硕、单位委派、社会人三种培养模式，衔接方式不同 |
| ③ **职称** | 待遇与岗位的核心标尺 | 医师（初级/住院医师）→ 主治医师（中级）→ 副主任医师（副高）→ 主任医师（正高） |

### 2.2 职称 ↔ 事业单位专业技术岗位等级对照

| 职称层级 | 对应专技岗位等级 |
|---|---|
| 正高级 | 专技 **一至四级** |
| 副高级 | 专技 **五至七级** |
| 中级 | 专技 **八至十级** |
| 初级 | 专技 **十一至十三级** |

实证校验：崇川岗位1「三级副主任医师 / 专技七级」（副高↔七级 ✅）；岗位2「三级主治医师 / 专技十级」（中级↔十级 ✅）。
> 岗位名称里的"三级""二级"是**岗位内部档次**，具体以公告为准，不做推算。

### 2.3 时间轴怎么画给家长看（可复用模板）

```
医学本科(5年) → 执业医师资格考试 → 住培(一般3年) → 主治医师(中级) → 副高 → 正高
   ↑ 起点               ↑ 有证才能行医        ↑ 多数医院招聘的硬门槛    ↑ 晋升需年限+业绩+论文
```

⛔ 别写成"毕业即就业"。这条路线的真实长度，是医院稿对家长最有价值的一句真话。

## 3. 身份三分法（"有没有编"——读者第一问）

| 身份 | 怎么从公告看出来 | 通俗解释（可写） | ⛔ 不能写 |
|---|---|---|---|
| **事业编制（编内）** | 有**人社部门备案号**（如「锡人社事招公告备〔2026〕28号」）；公告写「**办理进编手续**」「经核准公开招聘事业单位工作人员」 | 纳入编制管理，岗位等级对应职称序列 | 不得承诺"铁饭碗" |
| **备案制 / 员额制**（编制备案制） | 公告写明"备案制""人员控制总量管理""员额" | 岗位在总量内，待遇参照同级，但**不落到个人编制** | 不得等同于"编制" |
| **编外 / 合同制** | 公告写"编外""劳动合同""人事代理""同工同酬" | 与用人单位直签劳动合同 | 不得写"等同事业编" |
| **劳务派遣 / 政府购买服务岗** | 公告写"劳务派遣""购买服务岗位""第三方公司" | 劳动关系在第三方公司 | 不得与"单位直接聘用"混谈 |

> 🔴 **判定原则**：**只认公告原文用词**。公告没写的（尤其经费渠道、是否备案制），一律写「**公告未披露**」。
> ⛔ 严禁由"是公立医院""有事业编编号"反推 薪酬/经费/必定有编。

### 3.1 经费渠道（常被混淆，单独讲）

| 渠道 | 含义 |
|---|---|
| 全额拨款 | 人员经费由财政全额负担 |
| 差额拨款 | 财政补助一部分，其余靠单位收入 |
| 自收自支 | 财政不负担人员经费 |

⚠️ 这三个词**只在公告/岗位表明确出现时才能写**。MEMORY §七已有伤口：此前在多篇文章里对经费渠道做过推断，属违规。

## 4. 政策词典（每条都是潜在钩子，但引用必核）

| 政策 | 通俗含义 | 对哪类读者值钱 |
|---|---|---|
| **"两个同等对待"** | 面向社会招收的普通高校应届毕业生住培对象，**住培合格并到医疗卫生机构就业的**，在招聘中与临床医学、口腔医学、中医专硕研究生同等对待（**紧缺专业岗位除外**）；经住培合格的**本科学历临床医师**，在招聘中与上述专硕同等对待 | 本科生（最大红利，家长普遍不知道） |
| **农村订单定向免费医学生** | 免学费住宿费并补助生活费，毕业后按协议到基层服务一定年限，**有编有岗** | 高三家长（⚠️ 必须同时写明服务期约束） |
| **毕业生身份认定** | 医院公告常列四种情形：当年毕业且报名时无工作单位 / 前 1–2 年毕业且完成学历认证且报名时无工作单位 / 基层服务项目服务期满考核合格后一定年限内 / 应届士官退役一年内 | 往届生、择业期考生 |
| **基层服务项目** | "三支一扶"、农村教师特岗、"西部计划"、"乡村振兴计划"；服务期满考核合格后一定年限内可按毕业生身份报考 | 择业期考生 |
| **县管乡用 / 县聘乡用** | 编制在县级，岗位在乡镇，用于基层卫生人才统筹 | 愿意下沉的求职者 |
| **最低服务期 / 失信库** | 聘用后须服务满 N 年；公示后被放弃或逾期不报到，记入公开招聘考生失信库一定年限 | 所有人（最容易被忽略的坑） |
| **3 年内未取得资格即解聘** | 部分公告规定：聘用后若干个考试周期内未取得执业资格或相应职称的，解除/终止聘用合同 | 应届入编者 |

> ⛔ 引用政策**必须写文件名或年份并核对现行有效**；⛔ 不得自行解释到分数、到具体年限以外的细节。

## 5. 容易写错的六处（错一次就是硬伤）

1. 把**医技岗**当成"不用考证的医师岗"或直接写成医师序列。
2. 把**执业药师**等同于医院药剂岗的准入资格。
3. 把**住培证**写成"可选项"——多数临床岗是硬门槛。
4. 把**"本科及以上学历"**写成"本科以上"（是否含本科由公告定，不得改口径）。
5. 把**年龄放宽档次**张冠李戴（博士/中级/高级/基层硕士是四档，各有对应出生日期）。
6. 把**公告正文"招聘 N 名"**当成实际开放岗位数——**以附件岗位表为准**。
