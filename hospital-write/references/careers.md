# Hospital-Write · L2「医学升学与择业稿」生产线

> **L2 = 面向高三家长、在校医学生的内容**，锚点不是某份公告，而是**政策与公开统计数据**。
> 这条线才是"学校、学生、家长"诉求的主战场（朱总 2026-09-29 拍板：两条线都收）。
>
> ⛔ **与 L1 的关键分界**：L1 必须回答"这条还能不能投"；L2 **不涉及具体岗位投递**，
> 因此**不写报名入口、不写 CTA 转化位中的"抓紧投递"话术**，改用"关注后续 / 进群获取"的中性表达。

---

## 1. 选题三分类（按流量潜力排序）

### A. 专业认知类（家长最容易搜、也最容易信谣）
- 临床医学 **五年制 vs 5+3 一体化**：差在哪，各自的证书路径
- **口腔 / 麻醉 / 影像 / 护理 / 预防**：同样是"学医"，就业面差多少
- 医学影像学毕业后 **是医师还是技师**（高频误区）
- 中医学、中西医临床医学的执业范围限制

### B. 路径规划类（在校生与复读/考研决策）
- 从本科到能独立执业：**要几年、要考几个证**
- 专业型硕士 vs 学术型硕士：毕业时手上多一张什么证
- 护理本科毕业后：**医院 / 社区 / 考研 / 专科护士** 四条路
- 想进三甲：学历、规培、论文的实际权重

### C. 政策红利类（最容易被家长忽略、最有转发动力）
- **农村订单定向医学生**：免学费＋有编有岗，代价是什么
- **"两个同等对待"**：本科住培合格人员被视为专硕同等，这条能改变什么
- 基层卫生人才倾斜政策（县管乡用、定向培养、学费补偿）

> 📌 **选题判定口诀**：一个问题如果能用**一句话 + 一张数据表**回答清楚，且答案会改变家长的决策，就值得写。

## 2. L2 骨架（六段，与 L1 不同）

| 段 | 写法 | 硬要求 |
|---|---|---|
| 1 **结论先行** | 首段一句话直接回答标题的问题（家长没耐心看铺垫） | ⛔ 不写"本文将分几个部分" |
| 2 **数据表** | 核心数据做成表格，每行标出处＋年份 | 数据必须可点开验证 |
| 3 **拆维度** | 按学制 / 证书 / 就业方向拆开讲 | 每个维度都要有可查证的出处 |
| 4 **时间轴** | 用可视化或表格画培养路径（见 medical-facts §2.3 模板） | 年限必须标注"现行口径，以当年为准" |
| 5 **常见误区** | 挑 3 条家长流传最广的错误说法逐条驳 | ⛔ 驳的是"说法"，不得点名攻击任何机构或个人 |
| 6 **行动清单 + CTA** | 3 条可执行动作（如「到所在省教育考试院核对选科要求」「到国家卫健委查目标医院等级」） | CTA 用中性表达，不写"抓紧投递" |

> ⛔ L2 **不套 job-write 8 段骨架**（AGENTS.md §2 红线 12 已确立：**无可投递窗口的内容不套招聘引擎**）。

## 3. 数据源白名单（写进核验记录）

| 可用 | 用途 |
|---|---|
| 教育部阳光高考网、各省教育考试院 | 招生计划、选科要求、批次 |
| 国家卫健委 / 省卫健委官网与统计公报 | 医院名录、等级、机构数与人员数 |
| 高校官网招生网与专业介绍 | 学制、学位类型、专业方向 |
| 研招网 / 学位网专业目录 | 专硕与学硕区分、专业代码 |
| 人社部职业分类大典 | 职业名称与类别 |

⛔ **不可用作数据源**：知乎/小红书经验帖、自媒体整理、"据说"、模型记忆。
⛔ **数据必须有年份**："据统计"而无年份＝不可采信。

## 4. 三条硬纪律（细则）

### ① 不给具体填报分数
各省当年录取数据多变，做不到核实就从**不写到具体分数/位次**。
替代写法：「最终录取位次与批次，以考生所在省份教育考试院当年公布为准。」

### ② 不给医院排名或水平背书
⛔ 禁写："江苏最好的三家""省内顶尖""首选"。
✅ 可写客观属性："三级甲等""XX 大学附属医院""国家临床重点专科 N 个"——且**每一项都要有官方出处**。
> 这是 SKILL.md §八 第 2 条的落地：既避开《医疗广告管理办法》风险，也避开投诉。

### ③ 政策必须写明文件号或年份，并复核现行性
写前到国家卫健委 / 省卫健委 / 教育部官网确认该文件**仍然有效**。
跨年复用旧稿前，**必须重新核对**——这是 L2 最可能悄悄出错的地方（政策废止后文章还在被搜到）。

## 5. 标题公式（L2 面向泛流量）

L2 的搜索词**不带单位名**，带的是"人生决策焦虑"：

| 结构 | 示例 |
|---|---|
| 反问＋数字 | 学医到底要几年才能独立执业？把时间轴摊开给你看 |
| 辨析型 | 医学影像毕业到底是医师还是技师？很多家长到现在还搞混 |
| 政策红利型 | 农村订单定向医学生免学费还有编，代价是这一条 |
| 对比型 | 临床5年制和5+3，差的不是两年，是这张证 |

⛔ 标题不得夸大焦虑（"千万别学医""学医就是坑"）——有投诉风险，且与本号定位不符。
✅ 收尾统一口径：给数据、给路径、给"自己去核对的入口"，最后一句留"欢迎来反驳我"。
