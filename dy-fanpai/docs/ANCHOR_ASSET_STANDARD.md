# 产品锚图素材规范（H3 / ComfyUI i2v 锚图）

> 目的：给生成后端（H3 i2v / Wan i2v / 即梦）提供「干净」锚图，防止电商
> 宣传图上的营销文字被原样生成进视频画面。
>
> 2026-08-05 实测（1501# 冰丝内裤）：宣传图全带字，只有 sku 白底图可用。

## 规则

1. **可用锚图 = 纯实物图**：白底 / 纯色底，产品主体居中，**无任何文字、Logo、
   认证图标、价格**。例：`1501#/sku/*（合并）.png`。
2. **不可用 = 宣传图**：印有营销文案的图（如"凉感因子""透气清爽""裸感""0.01cm"
   "高弹"等）**禁止**作为 H3/即梦锚图——模型会照抄图上文字进视频，产生
   违规宣称 + 画面污染。
3. 判断标准：放大看产品周围有无文字。拿不准就先 `Read` 看图确认。

## 各产品线可用锚图（已核实）

| 产品 | 可用锚图 | 不可用（仅作参考，勿当锚图） |
|---|---|---|
| 1501# 冰丝内裤（水墨山水） | `sku/01~05（合并）.png`（蓝白/浅绿/灰墨/浅蓝/冰川 5 色白底图） | `主图/*.jpg`、`images/*.jpg`（全部带营销文字） |

## 换新产品时

1. 先找出该产品的「白底实物图」目录（通常 `sku/` 或独立拍摄的 clean 图）。
2. 在 `planning/assets.json` 里把 `hero` / `内包装` / `hero_alt` 指向这些干净图。
3. 若只有宣传图，走「裁字」或重新拍摄 clean 图，不要直接喂给生成端。
