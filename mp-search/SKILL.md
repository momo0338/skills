# MP-Search: 微信搜一搜文章与全维度互动数据极速检索技能

## 一、概述

本技能专为**高效率、轻量化**的微信公众号文章检索场景打造。通过微信桌面端内置「搜一搜」，按指定关键词自动化检索公众号文章、按「最热」或「最新」排序筛选，极速提取文章的关键元数据、真实互动数据（阅读量、点赞、转发、收藏、评论）以及**微信官方标准文章链接**（`https://mp.weixin.qq.com/s/...`），并直接输出结构化对比总表。

> **核心原则**：
> - **严格原生取链**：打开每篇文章后，**必须精准触发右上角「•••」菜单 -> 点击「复制链接」**，直接读取系统剪贴板获取带服务端鉴权的真实官方标准短链（`https://mp.weixin.qq.com/s/<22位短码>`）。严禁使用任何占位符、伪造哈希或非官方拼凑 URL。
> - **轻量极速**：仅采集「元数据 + 互动数据 + 官方链接」，不在过程中执行繁重的整篇读屏或正文解析。
> - **流水线分工**：搜一搜采集链接与数据 -> 后续交由专用下载技能（如 `scrapling-fetcher` / `opencli weixin download`）进行批量正文下载与 AI 本地分析。

## 二、适用场景与触发词

- **触发词**：`mp-search`、`搜一搜`、`微信搜一搜`、`微信文章搜索`、`公众号搜一搜`、`微信热门文章数据`、`公众号最新文章`
- **典型场景**：
  1. 快速盘点某关键词下微信生态「最热」或「最新」Top 5~10 篇文章的真实热度与流量数据。
  2. 获取包含微信官方标准链接（`https://mp.weixin.qq.com/s/...`）的结构化链接清单。
  3. 为下游批量下载与知识库归档提供第一手高质量数据源。

## 四、极速执行工作流 (Fast Execution Pipeline)

```
1. 唤起微信搜一搜
   └─ 点击微信主界面「搜一搜」图标，置顶搜一搜窗口

2. 关键词检索与分类
   ├─ 输入目标关键词（如：江苏小学 教辅 推荐）
   └─ 切换至「文章」分类标签

3. 排序模式选择
   ├─ 【最热】排序：抓取历史沉淀高热爆款 Top N
   └─ 【最新】排序：抓取近期时效前沿推文 Top N

4. 顺序极速采集 (Top 1 ~ N)
   ├─ 打开第 i 篇文章 Tab
   ├─ 记录标题、公众号、发布时间
   ├─ 滚动到底部记录阅读量、点赞、转发、收藏、评论
   ├─ **点击右上角「•••」 -> 点击「复制链接」**，直接从系统剪贴板获取带鉴权的标准短链
   ├─ 正则校验短链格式（`^https://mp\.weixin\.qq\.com/s/[A-Za-z0-9_-]+$`），严禁伪造或占位符
   └─ 快捷键 ⌘W 快速关闭 Tab，回到列表处理下一篇

5. 产出交付总表并落盘
   └─ 格式化为 Markdown / CSV / JSON 对比表格，直接交付用户或落盘知识库
```

## 五、高效操作与坐标速查

1. **搜一搜 WebView 窗口尺寸与缩放**：
   - 窗口逻辑尺寸一般为 1512x859，截图像素约为 1.408x 缩放。
2. **快捷操作**：
   - 关闭当前文章 Tab 快速返回列表：`⌘W` (super+w)。
   - 快速滚动至正文底部查看互动数据：按 `End` 或 `Page_Down`。
3. **输出规范**：
   - **严格真链**：每一条链接都必须经由原生复制链接动作和正则校验，严禁正文猜测或伪造。
   - 默认输出清晰的 Markdown 汇总表格。
   - 所有链接均渲染为可点击的标准 Markdown 链接 `[URL](URL)`。
